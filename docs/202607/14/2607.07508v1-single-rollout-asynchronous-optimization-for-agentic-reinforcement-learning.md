## 摘要
强化学习 (RL) 在大语言模型 (LLM) 的后训练中变得日益重要。以往用于 LLM 的强化学习流水线大多采用同步和批次交替的方式，这对于长程智能体任务而言效率较低。最近，异步强化学习作为一种更高效的替代方案出现，它通过在 Rollout 到达时立即更新模型来提高效率。然而，现有的异步强化学习系统往往侧重于吞吐量，而对训练稳定性和任务有效性的研究尚不充分。例如，一个关键挑战在于广泛使用的 GRPO 框架中的组采样 (group-wise sampling) 并不自然地适用于异步智能体训练。在本文中，我们提出了单 Rollout 异步优化 (SAO)，旨在解决异步强化学习中的稳定性和离策 (off-policy) 挑战。为了减少离策效应并提升泛化能力，我们将组采样替换为单 Rollout 采样，即每个提示词仅使用一个 Rollout。我们还通过实用的价值模型训练设计进一步改进了这一单 Rollout 策略。为了增强优化稳定性，我们引入了严格的双侧 Token 级裁剪策略。SAO 能够稳定训练一千个步长，并在智能体编程和推理基准测试（如 SWE-Bench Verified、BeyondAIME 和 IMOAnswerBench）上持续优于 GRPO 及其变体。我们还证明了单 Rollout 强化学习在模拟在线学习设置中特别有效，此时模型必须适应不断演变的环境。为此，SAO 已成功部署在用于训练开源 GLM-5.2 模型 (750B-A40B) 的智能体强化学习流水线中。

## Abstract
Reinforcement learning (RL) is becoming increasingly important for post-training large language models (LLMs). Previous RL pipelines for LLMs were mostly synchronous and batch-interleaved, which is inefficient for long-horizon agentic tasks. Recently, asynchronous RL has emerged as a more efficient alternative by updating the model as rollouts arrive. However, existing asynchronous RL systems often emphasize throughput, while leaving training stability and task effectiveness largely underexplored. For example, a key challenge is that group-wise sampling in the widely-used GRPO framework does not naturally fit asynchronous agentic training. In this paper, we present Single-rollout Asynchronous Optimization (SAO) to address the stability and off-policy challenges in asynchronous RL. To reduce off-policy effects and improve generalization, we replace group-wise sampling with single-rollout sampling, that is, using one rollout per prompt. We further improve this single-rollout strategy with practical value-model training designs. To improve optimization stability, we introduce a strict double-side token-level clipping strategy. SAO is able to train stably for one thousand steps and consistently outperform GRPO and its variants on agentic coding and reasoning benchmarks, such as SWE-Bench Verified, BeyondAIME, and IMOAnswerBench. We also demonstrate that single-rollout RL is particularly effective in a simulated online learning setting, where the model must adapt to changing evolving environments. To this end, SAO is successfully deployed in the agentic RL pipeline for training the open GLM-5.2 model (750B-A40B).

### 1. 核心问题与整体含义
*   **研究背景**：大语言模型（LLM）的后训练正从监督微调转向强化学习（RL）。传统的 RL 流水线（如 PPO、GRPO）多为**同步且批次交替**的，但在处理长程智能体（Agentic）任务时效率极低。由于不同任务的轨迹长度差异巨大，同步机制会导致 GPU 集群在等待最慢样本（Stragglers）时出现大量空闲。
*   **核心问题**：异步 RL 虽然能提高吞吐量，但面临两大挑战：
    1.  **训练不稳定性**：异步更新导致 Rollout 模型与训练模型之间存在严重的“策略滞后”（Policy Lag），引发离策（Off-policy）效应。
    2.  **算法不匹配**：目前主流的 GRPO 依赖组采样（Group-wise sampling）来估计优势函数，这在异步环境下会造成额外的等待延迟，且不符合环境仅提供单次反馈的在线学习场景。

### 2. 方法论：SAO (Single-rollout Asynchronous Optimization)
SAO 的核心思想是放弃组采样，采用**单样本异步优化**，并通过一系列设计确保稳定性：
*   **双侧重要性采样 (DIS)**：
    *   直接利用 Rollout 引擎生成的 log-probabilities 作为行为概率，避免了维护多个旧策略模型副本的开销。
    *   引入严格的**双侧 Token 级裁剪与掩码**：不仅裁剪梯度，还将超出信任区域 $[1-\epsilon_\ell, 1+\epsilon_h]$ 的 Token 直接从梯度计算中掩码掉，以应对极端的策略漂移。
*   **优化的价值模型（Critic）训练**：
    *   **快于策略的更新**：策略模型每更新一次，价值模型更新 $K$ 次（实验中 $K=2$），确保优势估计能快速跟上策略变化。
    *   **冻结注意力机制**：在 RL 阶段冻结价值模型的 Attention 层，仅微调 MoE 投影层，以减少梯度波动，增强数值稳定性。
*   **跳过观察的 Token 级 GAE (Skip-Observation GAE)**：
    *   针对智能体任务中“动作-观察”交替的结构，SAO 在计算广义优势估计（GAE）时，跨越环境反馈（Observation）Token，直接连接前后两个动作 Token。这避免了将环境引入的随机噪声传播到优势函数中。

### 6. 主要结论与发现
*   **性能卓越**：SAO 在所有基准测试中均优于 GRPO 及其变体。例如在 AIME2025 上，SAO 将准确率从基准的 80.4% 提升至 97.3%。

*   **在线适应性**：在模拟在线学习中，SAO 的价值模型能比滑动窗口方法更快地捕捉到奖励分布的变化，实现策略的快速对齐。

### 7. 优点（亮点）
*   **效率与效果兼得**：既保留了异步 RL 的高吞吐量，又通过算法创新解决了其固有的稳定性问题。
*   **单样本设计的实用性**：相比组采样，单样本采样更符合真实世界的在线交互逻辑，且消除了“短板效应”（等待最慢样本）。
*   **针对智能体特性的优化**：Skip-Observation GAE 深刻理解了智能体轨迹中模型生成内容与环境反馈的区别。

### 8. 不足与局限
*   **显存开销**：由于引入了独立的价值模型（Critic），相比于无 Critic 的 GRPO，SAO 在训练时需要更多的显存来存储价值模型的参数和梯度。
*   **基础设施依赖**：SAO 需要推理引擎能够实时返回并保存 Rollout 时的 log-probabilities，这对异步训练系统的工程实现有一定要求。
*   **任务类型局限**：实验主要集中在具有明确奖励（如数学对错、编程通过）的硬逻辑任务上，在奖励信号模糊的开放式对话任务中的表现尚待验证。
