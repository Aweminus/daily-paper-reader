## 摘要
思维链（CoT）提示被广泛用作视觉语言模型（VLM）的测试时缩放策略，但当 VLM 生成更长的推理轨迹时，究竟是什么得到了扩展仍不清楚。我们探究 CoT 是否需要持续访问图像 token，还是主要在模型前向传播早期已获取的视觉信息上进行操作。我们引入了“视觉访问扫描”（Visual Access Sweep），这是一种因果干预方法，它沿着层深度和生成时间屏蔽从生成 token 查询到图像 token 键的注意力，并将“视觉访问边界”（VAB）定义为保持任务准确性的最小访问区域。在来自 Qwen2.5-VL 和 InternVL3 的六种模型配置中，无 CoT 直接回答和 CoT 提示均表现出有限的 VAB。在 Qwen2.5-VL-32B 以及 14B 和 38B 规模的 InternVL3 中，当以无 CoT 全访问目标为基准评估 CoT 时，尽管生成长度显著增加，其 VAB 层与无 CoT 边界的差异最多仅为两层。这表明 CoT 提升性能的主要方式并非在整个推理轨迹中延长对图像 token 的直接访问，而是在源自图像的隐藏状态信息上扩展语言侧的计算。我们进一步表明，CoT 的增益受到感知读取（perceptual readout）的限制。当模型能够可靠地读取所查询的视觉属性时，CoT 会有所帮助；但当读取不可靠时，CoT 则无效。符号属性真值实验表明，一旦以文本形式提供真实属性，CoT 就能提高计数能力；而单对象探测与解码检查显示，困难属性虽然可以从隐藏状态中线性恢复，但模型自身却难以将其输出。综上所述，这些分析表明瓶颈在于读取而非计数。

## Abstract
Chain-of-Thought (CoT) prompting is widely used as a test-time scaling strategy for Vision-Language Models (VLMs), but it remains unclear what is extended when VLMs generate longer reasoning traces. We ask whether CoT requires continued access to image tokens, or whether it mainly operates over visual information already made available earlier in the forward pass. We introduce Visual Access Sweep, a causal intervention that masks attention from generated-token queries to image-token keys along layer depth and generation time, and define the Visual Access Boundary (VAB) as the minimal access region that preserves task accuracy. Across six model configurations from Qwen2.5-VL and InternVL3, both no-CoT direct answering and CoT prompting exhibit finite VABs. In Qwen2.5-VL-32B and InternVL3 at 14B and 38B scales, when CoT is evaluated against the no-CoT full-access target, its VAB layer differs from the no-CoT boundary by at most two layers, despite substantially longer generations. This suggests that CoT does not primarily improve performance by prolonging direct image-token access throughout the reasoning trace, but by extending language-side computation over image-derived hidden-state information. We further show that CoT gains are constrained by perceptual readout. CoT helps when the queried visual attribute can be reliably read out by the model, but not when that readout is unreliable. A symbolic-attribute oracle shows that CoT can improve counting once ground-truth attributes are supplied as text, while a single-object probe-vs-decode check shows that hard attributes can be linearly recoverable from hidden states yet difficult for the model itself to output. Together, these analyses place the bottleneck at readout rather than counting.

# 视觉语言模型推理中的视觉访问边界（VAB）论文总结

## 1. 核心问题与整体含义
该论文探讨了视觉语言模型（VLM）在进行思维链（CoT）推理时的内在机制。研究动机在于：虽然 CoT 能显著提升 VLM 的性能，但目前尚不清楚这种提升是源于模型在推理过程中**持续直接访问图像信息**，还是仅仅在**语言侧对早期提取的视觉特征进行深度处理**。

论文通过引入“视觉访问边界”（Visual Access Boundary, VAB）这一概念，试图厘清视觉感知与下游推理之间的因果关系，并识别出限制 VLM 推理性能的真正瓶颈。

## 2. 方法论
### 核心思想
作者提出了一种名为**视觉访问扫描（Visual Access Sweep）**的因果干预方法。通过在推理生成过程中，有选择地屏蔽（Masking）从生成 token 到图像 token 的注意力权重，来观察模型性能的变化。

### 关键技术细节
*   **干预维度**：在“层深度（Layer Depth, $\ell$）”和“生成时间（Generation Time, $t$）”两个维度上进行扫描。
*   **注意力屏蔽**：定义一个矩形区域 $(\ell_{cutoff}, t_{cutoff})$，仅允许在此区域内的生成 token 访问图像 token。对于区域外的注意力权重，在 Softmax 前将其设为 $-\infty$，使其权重归零。
*   **视觉访问边界（VAB）**：定义为在保持任务准确率下降不超过容差 $\epsilon$（默认为 0.05）的前提下，所需的最小访问区域 $(\ell^*, \tau^*)$。
*   **因果推断**：如果移除后期层或后期 token 的视觉访问后性能依然保持，则说明这些直接访问在功能上是冗余的，模型此时依赖的是残差流中携带的隐藏状态信息。

## 3. 实验设计
### 数据集与场景
1.  **受控属性计数任务**：基于合成图像，固定推理操作（计数），改变查询属性（颜色、形状、位置、角度、大小），以隔离感知难度对推理的影响。
2.  **GQA 真实场景问答**：使用 GQA 数据集的平衡验证集（Yes/No 子集），验证 VAB 现象在真实图像上的普适性。

### 对比模型与基准
*   **模型家族**：Qwen2.5-VL（3B, 7B, 32B）和 InternVL3（8B, 14B, 38B）。
*   **对比方法**：直接回答（Direct Prompting） vs. 思维链推理（CoT Prompting）。
*   **基准线**：全访问（Full-access）情况下的模型准确率。

## 6. 主要结论与发现
1.  **有限的 VAB 存在**：无论是直接回答还是 CoT，都存在明显的视觉访问边界。超过一定深度后，直接访问图像 token 对性能几乎没有贡献。
2.  **CoT 不依赖延长视觉访问**：尽管 CoT 生成的推理轨迹比直接回答长几十倍，但其 VAB 在层深度上与直接回答非常接近（差异通常在 2 层以内）。这证明 CoT 主要是扩展了语言侧的计算，而非视觉读取。
3.  **感知读取是主要瓶颈**：CoT 的增益受限于模型将视觉属性转化为“可用符号”的能力。如果模型无法从隐藏状态中准确解码出属性（如角度、大小），即使增加推理步数也无法提升性能。
4.  **Oracle 验证**：一旦通过文本直接提供属性真值（绕过视觉感知），CoT 在所有属性上的计数性能均大幅提升，进一步确认瓶颈在于感知读取而非逻辑计数。

## 7. 优点
*   **因果干预视角**：跳出了“注意力权重高低”的观察性陷阱，通过屏蔽实验直接证明了视觉访问的“必要性”。
*   **任务解耦设计**：通过固定计数操作、改变感知属性，巧妙地分离了感知瓶颈与推理瓶颈。
*   **跨架构验证**：在 Prefix-fusion（Qwen/InternVL）和 Cross-attention（Llama-3.2-Vision）两种主流架构上均验证了结论的有效性。

## 8. 不足与局限
*   **任务类型限制**：主要集中在计数和简单的视觉问答，尚未覆盖需要“迭代视觉搜索”或“主动感知”的复杂长程任务。
*   **机制解释尚浅**：虽然确定了 VAB 的存在，但对于视觉信息是如何在残差流中被编码并传递到后期层的具体机制，仍需进一步研究。
*   **应用范围**：结论主要适用于 Decoder-only 的主流 VLM 架构，对于具有显式外部存储或多轮感知反馈的模型可能不完全适用。
