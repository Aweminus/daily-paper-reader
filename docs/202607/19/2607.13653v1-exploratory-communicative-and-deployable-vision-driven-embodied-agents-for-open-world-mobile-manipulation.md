## 摘要
具身智能体的现实世界部署需要主动探索、视觉定位以及交互式意图消歧。然而，现有的框架通常依赖于特权仿真器状态或假设指令完整，从而绕过了现实的部署挑战。为了弥补这一差距，我们提出了 REAL，一个用于开放世界移动操作的智能体框架。REAL 在没有先验感知的情况下建立了仿真到现实一致的环境 API，并集成了一个模拟用户以实现人机在环交互。在该环境中，我们设计了多样的任务组合来驱动数据采集、监督微调和在线强化学习，从而系统地优化智能体性能。为了全面评估该方法，我们引入了 REAL-Bench，这是一个涵盖主动探索、视觉干扰、关节操作和交互式消歧等 241 个任务的基准测试。实验结果表明，我们训练的智能体在交互式任务上的成功率达到 56.9%，优于领先的商业闭源 VLM。进一步的实证分析表明，我们的分层训练流水线成功对齐了模型的工具使用能力，同时在扩展的探索视野下保持了鲁棒的开放词汇推理。最后，我们在物理双臂移动机器人上部署并评估了我们的框架，在 60 个真实世界回合中实现了 78.3% 的端到端成功率。这些物理试验展示了对未知家庭场景的鲁棒零样本迁移能力，验证了我们的仿真到现实一致性设计成功弥合了长程移动操作的现实差距。代码可在 https://github.com/InternRobotics/REAL 获取。

## Abstract
Real-world deployment of embodied agents requires active exploration, visual grounding, and interactive intent disambiguation. However, existing frameworks often rely on privileged simulator states or assume complete instructions, bypassing realistic deployment challenges. To bridge this gap, we present REAL, an agentic framework for open-world mobile manipulation. REAL establishes sim-to-real-consistent environment APIs without oracle perception and integrates a simulated user to enable human-in-the-loop interaction. Within this environment, we design diverse task compositions to drive data collection, supervised fine-tuning, and online reinforcement learning, systematically optimizing agent performance. To comprehensively evaluate this approach, we introduce REAL-Bench, a benchmark spanning 241 tasks across active exploration, visual distraction, articulated manipulation, and interactive disambiguation.   Experimental results demonstrate that our trained agent outperforms leading commercial closed-source VLMs on interactive tasks with a 56.9% success rate. Further empirical analysis reveals that our hierarchical training pipeline successfully aligns the model's tool-use capabilities while maintaining robust open-vocabulary reasoning under extended exploration horizons. Finally, we deploy and evaluate our framework on a physical dual-arm mobile robot, where it achieves a 78.3% end-to-end success rate over 60 real-world episodes. These physical trials demonstrate robust zero-shot transferability to unseen household scenarios, validating that our sim-to-real-consistent design successfully bridges the reality gap for long-horizon mobile manipulation. Code is available at https://github.com/InternRobotics/REAL.

### 1. 核心问题与研究动机
*   **核心问题**：现有的具身智能体（Embodied Agents）在开放世界移动操作中面临三大挑战：**缺乏主动探索能力**（依赖全局地图或特权信息）、**缺乏交互消歧能力**（假设指令总是完整明确的）、以及**仿真与现实的鸿沟**（依赖模拟器的内部状态而非原始视觉输入）。
*   **研究背景**：虽然大语言模型（LLM）和视觉语言模型（VLM）提升了机器人的推理能力，但在实际部署时，机器人往往因为无法处理模糊指令、无法在未知环境中定位目标或过度依赖模拟器“上帝视角”而失败。

### 2. 方法论：REAL 框架
REAL 框架旨在构建一个具备探索性、交流性和可部署性的智能体，其核心组成部分包括：
*   **虚实一致的环境 API**：摒弃了模拟器提供的特权状态（如物体坐标、类别标签），仅使用机器人可获取的原始数据（RGB-D 图像、LiDAR、关节状态）。通过统一的 API 接口，确保智能体在仿真环境和物理世界中使用相同的感知和控制逻辑。
*   **模拟用户交互机制**：在训练循环中引入一个“模拟用户”，能够根据环境状态生成模糊指令，并在智能体提问时提供反馈。这使得智能体能够学习何时通过对话消除歧义（如“你要哪种颜色的杯子？”）。
*   **分层训练管线**：
    *   **监督微调 (SFT)**：利用专家轨迹数据，使模型掌握基本的工具调用、多轮对话和逻辑推理能力。
    *   **在线强化学习 (Online RL)**：采用 PPO 算法，在仿真环境中进行大规模在线探索。重点优化智能体在长程任务中的视觉定位、主动探索和异常处理能力，弥补 SFT 在处理分布外（OOD）状态时的不足。
*   **分层架构**：高层 VLM 充当“大脑”进行决策和工具调用，底层控制器负责具体的导航（Navigation）和操作（Manipulation）执行。

### 3. 实验设计
*   **Benchmark (REAL-Bench)**：包含 241 个精心设计的任务，涵盖四大维度：主动探索（Exploration）、视觉干扰（Distraction）、关节物体操作（Articulated Objects）和交互式消歧（Disambiguation）。

### 5. 实验数量与充分性
*   **实验规模**：REAL-Bench 的 241 个任务提供了较为全面的覆盖。物理实验进行了 60 个回合（Episodes），这在具身智能体论文中属于较为扎实的验证规模。

### 6. 主要结论与发现
*   **RL 的关键作用**：在线 RL 显著提升了智能体在复杂环境中的鲁棒性，尤其是在需要长程移动和处理视觉遮挡的场景下，成功率远高于仅经过 SFT 的模型。
*   **超越通用模型**：经过针对性训练的 REAL 智能体在交互式任务上的成功率（56.9%）优于 GPT-4o 等通用大模型，证明了具身能力的对齐（Alignment）至关重要。
*   **强大的零样本迁移**：得益于虚实一致的 API 设计，在仿真中训练的模型无需修改即可直接部署到物理机器人上，并实现了 78.3% 的端到端成功率。

### 7. 优点
*   **虚实一致性**：解决了具身智能体研究中常见的“模拟器特权”问题，使研究成果更具实用价值。
*   **交互能力**：将人机交互（消歧）纳入训练闭环，使机器人不再是机械执行者，而是能主动沟通的协作伙伴。
*   **开源贡献**：提供了完整的 Benchmark 和代码库，有助于推动开放世界移动操作的研究。

### 8. 不足与局限
*   **底层技能依赖**：智能体的表现高度依赖于预定义的底层控制器（如导航和抓取算法）。如果底层技能失败，高层 VLM 往往难以通过纯视觉推理进行补救。
*   **推理延迟**：作为基于 VLM 的框架，端到端的推理延迟可能限制其在极高动态环境下的表现。
*   **场景多样性**：虽然在家庭场景表现良好，但在更复杂的工业或户外环境中的泛化能力仍有待验证。
