## 摘要
具有显式视觉定位（即定位支持每个答案的精确文档区域）的高效多模态文档问答仍是一个开放性挑战。目前的方法分为两类：有监督微调（SFT），它需要大规模标注数据集且容易达到优化瓶颈；以及以推理为中心的强化学习（RL），它依赖于冗长的中间推理轨迹，在没有明显收益的情况下增加了推理 Token 的成本。我们提出了 Perception-RFT，这是一个将群体相对策略优化（GRPO）应用于多模态文档问答的训练框架，它绕过中间推理 Token，直接将视觉特征与结构化定位输出对齐。为了严格评估推理的必要性，我们在相同的奖励设置下构建了一个推理变体。我们发现，在 4B 参数规模下，具备推理能力的模型在训练过程中会抑制其推理轨迹，收敛于基于直接感知的策略，使单次查询的推理 Token 长度减少了 60% 以上，而具备推理能力的 RL 表现不如纯感知训练。通过对 Qwen3-VL-4B 优化动态的细粒度分析，我们证实了文本领域后训练中存在的 SFT 饱和与冷启动 RL 不稳定性同样延伸到了多模态领域，并发现了一种此前未被描述的“定位分歧”（Grounding Divergence）：在联合 RL 优化下，两个分布外（OOD）基准测试（4,828 个样本）中语义鲁棒性与几何精度之间的选择性权衡。我们进一步表明，较早地从 SFT 转向 RL 可以在减少 65% 训练数据的情况下实现相当的精度。

## Abstract
Efficient multimodal document question answering with explicit visual grounding, locating the precise document region that supports each answer remains an open challenge. Current approaches bifurcate into Supervised Fine-Tuning (SFT), which requires large annotated datasets and reaches optimization plateaus, and reasoning-centric Reinforcement Learning (RL), which depends on verbose intermediate traces that inflate inference token cost without clear benefit. We introduce Perception-RFT, a training framework that applies Group Relative Policy Optimization (GRPO) to multimodal document QA, bypassing intermediate reasoning tokens to directly align visual features with structured grounding outputs. To rigorously evaluate the necessity of reasoning, we construct a reasoning variant under identical reward settings. We find that reasoning-enabled models suppress their reasoning traces during training, converging to direct perception-based policies at the 4B parameter scale, reducing per-query inference token length by more than 60%, while reasoning-enabled RL underperforms perception-only training. Through a fine-grained analysis of Qwen3-VL-4B optimization dynamics, we confirm that SFT saturation and cold-start RL instability established in text-domain post-training extend to multimodal, and identify a previously uncharacterized Grounding Divergence: a selective trade-off between semantic robustness and geometric precision on two out of distribution (OOD) benchmarks (4,828 samples) under joint RL optimization. We further show that an early SFT$\rightarrow$RL transition achieves comparable precision with 65% less training data.

### 1. 核心问题与整体含义
论文的核心问题是：**在处理文档视觉定位任务时，显式的推理过程（如思维链 CoT）是否真的必要？**
*   **背景：** 现有的多模态大模型（MLLM）在文档定位上表现脆弱。目前的改进方法要么依赖大规模有监督微调（SFT），但容易遇到性能瓶颈；要么依赖以推理为中心的强化学习（如 DeepSeek-R1 模式），但这会产生冗长的中间推理 Token，显著增加推理成本和延迟。
*   **动机：** 作者假设文档定位本质上是一个“感知主导”的任务，直接将视觉特征映射到坐标输出可能比通过推理中介更高效。

### 2. 方法论：Perception-RFT
论文提出了 **Perception-RFT** 框架，旨在通过无推理对齐优化模型。
*   **核心思想：** 利用 **GRPO（组相对策略优化）** 算法，在不生成任何中间推理 Token（如 `<think>`）的情况下，直接优化模型输出结构化的 JSON 结果（包含答案文本和边界框坐标）。
*   **关键技术：**
    *   **直接感知约束：** 通过系统提示词强制模型“停止思考”，禁止输出解释或推理步骤，仅输出最终 JSON。
    *   **门控密集感知奖励（Gated Dense Perception Reward）：** 奖励函数由三部分组成：
        1.  **格式一致性：** 是否为合规 JSON。
        2.  **语义精确度：** 使用 ANLS（平均归一化编辑距离）衡量文本提取准确性，并进行二次方缩放以加重惩罚。
        3.  **门控定位奖励：** 这是一个关键创新。当 IoU 低于阈值（0.6）时，奖励被大幅压缩（塑造阶段）；一旦超过阈值，奖励大幅跳升（成功阶段）。这种“悬崖式”设计防止了模型通过预测超大边界框来投机性地获取 IoU 奖励。

### 3. 实验设计
*   **数据集：**
    *   **训练集：** 整合了 DocILE 和 FormNLU，包含约 2.3 万个金融文档 QA 样本。
    *   **分布内（ID）评估：** 训练集的留出部分（6,194 个样本）。
    *   **分布外（OOD）评估：** 使用 DOGR-Bench（艺术海报、图表、科学 PDF）和 MMDocBench（报告、收据、信息图），共 4,828 个样本。
*   **对比方法：**
    *   **基准：** Qwen3-VL-4B（零样本及 SFT 版本）。
    *   **RFTs：** SFT 后的强化学习。
    *   **RFTb：** 冷启动强化学习（直接在基座模型上进行 RL）。
    *   **Reasoning-RFTb：** 允许生成推理 Token 的 RL 变体。
    *   **外部参考：** Gemini 3.0 Flash。

### 4. 资源与算力
*   **硬件：** 使用了 **单张 NVIDIA A100 (80GB)** GPU。
*   **软件/优化：** 使用了 **Unsloth** 框架进行快速微调，并采用 **LoRA**（r=16, α=16）进行参数高效适配。
*   **训练量：** SFT 阶段为 3 个 Epoch；RL 阶段仅使用了 6000 个样本（不到 SFT 计算量的 10%）。

### 5. 实验数量与充分性
*   **实验规模：** 论文进行了多维度的对比，包括 ID 和 OOD 测试、SFT 饱和度分析、RL 启动策略分析以及推理消融实验。
*   **充分性：** 实验设计较为严谨。通过在相同奖励设置下对比“有推理”和“无推理”变体，客观地证明了推理在感知任务中的冗余性。使用了近 5000 个 OOD 样本，增强了结论的说服力。

### 6. 主要结论与发现
*   **推理抑制现象：** 在 4B 参数规模下，即使允许模型推理，模型在训练过程中也会自动压缩并最终放弃推理轨迹，转向直接感知，推理 Token 长度减少了 **62%**。
*   **性能超越：** 无推理的 Perception-RFT 在定位精度上优于带推理的 RL，且在 ID 任务上超过了规模大得多的 Gemini 3.0 Flash。
*   **定位分歧（Grounding Divergence）：** 发现 RL 优化存在非对称性——几何定位精度在 OOD 场景下提升显著，但语义提取的鲁棒性可能会略微下降。
*   **数据效率：** 早期从 SFT 转向 RL（RFTs-Early）可以在减少 **65%** 训练数据的情况下，达到与全量 SFT 相当甚至更好的定位效果。

### 7. 优点
*   **高效性：** 显著降低了推理时的计算开销（Token 数大幅减少）。
*   **训练稳定性：** 提出的门控奖励机制有效解决了模型在 RL 早期容易收敛到“大框”亚稳态的问题。
*   **实用性：** 证明了在特定感知任务中，不需要昂贵的 CoT 也能获得顶级性能，对工业界部署具有指导意义。

### 8. 不足与局限
*   **模型规模限制：** 实验主要集中在 4B 参数模型，尚不确定这些结论（如推理自动消失）是否适用于 70B 或更大规模的模型。
*   **推理数据缺失：** 由于缺乏带推理标注的文档定位数据集，无法进行“推理 SFT $\rightarrow$ 推理 RL”的完整链路对比，目前的推理消融仅限于冷启动 RL。
*   **语义权衡：** 论文观察到了语义鲁棒性与几何精度之间的权衡，但尚未提出完美的解决方案来同时最大化这两者。
