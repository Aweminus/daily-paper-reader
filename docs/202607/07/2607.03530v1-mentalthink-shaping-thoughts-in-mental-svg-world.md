## 摘要
我们介绍了 MentalThink，这是一种视觉-符号推理范式，为多模态大语言模型（MLLMs）提供了一种可执行的“心理”可视化机制。MentalThink 的核心是一个“以 SVG 思考”（think-with-SVG）的流水线，模型在其中学习生成、渲染和解释可缩放矢量图形（SVG）代码，将其作为多轮推理的中间视觉表示。通过创建结构化的矢量草图，模型可以将空间假设外部化，通过确定性渲染对其进行检查，并在受限的几何空间内进行推理，从而有效地模拟人类的心理意象过程。我们通过一个两阶段训练框架实例化了这一范式，该框架结合了用于 SVG 语法对齐的有监督微调（SFT）和多轮强化学习（RL），以鼓励对中间视觉假设进行迭代检查、修正和完善。广泛的评估表明，MentalThink 在空间理解和推理基准测试中取得了优异的性能（例如，在 VSIBench 上达到 55.1%，在 MindCube 上达到 76.0%），这表明可执行的矢量图形为动态视角切换、视觉反思和组合式场景构建提供了一个可验证的视觉工作空间。

## Abstract
We introduce MentalThink, a visual-symbolic reasoning paradigm that equips Multimodal LLMs (MLLMs) with an executable mechanism for "mental" visualization. The core of MentalThink is a think-with-SVG pipeline, where the model learns to generate, render, and interpret scalable vector graphics (SVG) code as an intermediate visual representation for multi-turn reasoning. By creating structured vector sketches, the model can externalize spatial hypotheses, inspect them through deterministic rendering, and reason within a constrained geometric space, effectively mimicking the human process of mental imagery. We instantiate this paradigm through a two-stage training framework, combining Supervised Fine-Tuning (SFT) for SVG syntactic alignment with multi-turn Reinforcement Learning (RL) to encourage iterative inspection, revision, and refinement of intermediate visual hypotheses. Extensive evaluations demonstrate that MentalThink achieves superior performance on spatial understanding and reasoning benchmarks (e.g., 55.1% on VSIBench, 76.0% on MindCube), showing that executable vector graphics provide a verifiable visual workspace for dynamic perspective taking, visual reflection, and compositional scene construction.

*   **核心挑战**：现有的多模态大模型（MLLMs）主要依赖文本思维链（CoT），缺乏结构化的空间表征，容易在几何推理中产生“幻觉”；而基于边界框（BBox）或外部工具的方法要么过于简化，要么破坏了端到端的推理连贯性。
*   **论文目标**：提出一种名为 **MentalThink** 的新范式，将可缩放矢量图形（SVG）作为模型的“心理草图”，使模型能够通过生成、渲染和解释 SVG 代码来进行可验证的视觉推理。

### 2. 方法论
*   **核心思想（Think-with-SVG）**：将 SVG 视为一种结构化的视觉语言。模型在推理过程中不直接输出答案，而是先编写 SVG 代码来构建内部视觉模型，通过环境渲染得到反馈，再基于该反馈进行修正或得出结论。
*   **关键技术细节**：
    *   **SVG 空间定义**：利用 SVG 的确定性映射（代码到像素）、组合语义（由基本几何体构建复杂场景）和参数化控制（坐标、尺寸、颜色）特性。
    *   **两阶段训练框架**：
        1.  **阶段一：语法对齐（SFT）**：通过 20 万条数据（包括视觉-语法对齐、思维外部化、基础空间感知）训练模型，使其掌握 SVG 的编写规范和基础空间建模能力。
        2.  **阶段二：多轮强化学习（RL）**：采用 **GRPO** 算法。模型在推理循环中生成假设（SVG），环境进行确定性渲染并反馈，模型根据反馈迭代。
    *   **奖励函数**：结合了**格式奖励**（SVG 是否可渲染）和**答案奖励**（最终结果是否正确），引导模型生成既符合逻辑又具备视觉准确性的中间表征。

### 3. 实验设计

*   **对比实验**：专门对比了“以文本思考”、“以边界框思考”与“以 SVG思考”三种范式，证明了 SVG 在空间诱导偏差（Inductive Bias）上的优越性。
*   **充分性评价**：实验设计较为客观公平，通过固定 7B 参数量的骨干网络，证明了性能提升源于推理范式的创新而非单纯的模型缩放。

### 6. 主要结论与发现
*   **性能飞跃**：MentalThink 在 MindCube 上从基座的 36.0% 提升至 **76.0%**（+40%），在 VSIBench 上提升了 24.1%。
*   **系统 1 与系统 2 的自适应切换**：模型表现出类似人类的认知行为。对于简单感知任务，模型倾向于直接给出答案（系统 1）；对于复杂推理任务，模型会自动调用 SVG 生成进行多轮迭代（系统 2），SVG 调用率从 18.5% 飙升至 63.7%。
*   **涌现的推理模式**：模型学会了**动态视角转换**（以他人视角看物体）、**反思性视觉修正**（发现坐标错误并重画）和**组合式场景构建**（整合多视角信息）。

### 7. 优点
*   **创新性强**：首次将 SVG 作为 MLLM 的中间推理模态，而非仅仅是生成目标。
*   **可验证性**：SVG 代码是可执行的，为模型提供了一个确定性的、非黑盒的“视觉工作空间”。
*   **协同效应**：成功将符号化的代码能力与感知化的视觉能力在强化学习框架下统一起来。

### 8. 不足与局限
*   **数据依赖**：高质量的“SVG 思维链”数据极度匮乏，高度依赖复杂的合成数据流水线。
*   **推理开销**：多轮 SVG 生成和渲染会显著增加推理延迟和 Token 消耗。
*   **领域局限**：目前主要集中在空间和几何推理，对于非空间类的抽象逻辑推理（如常识推理、情感分析）的适用性尚未得到验证。
