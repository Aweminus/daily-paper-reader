## 摘要
智能体多模态模型通过代码对图像执行多种操作，并对返回的视图进行推理，这是细粒度视觉问答的一种有效范式。然而，代码操作可能是有效的、冗余的或具有误导性的。仅基于结果的奖励无法精确区分这些情况，而现有的过程奖励要么无法将最终的正确性归因于单个工具调用，要么需要外部评判模型。为解决这一问题，我们引入了工具增强型信用优化（TACO），这是一种针对代码工具智能体的 GRPO 变体，构建在两个耦合的优势通道之上。第一个是差分答案探测奖励（DAPR），这是一种自监督、无需评判模型的工具贡献优势，它根据每个工具调用对正确回答的影响进行信用分配。插入模型推理过程中的探测标记（Probe tokens）会诱导出模型在有无工具情况下的预测，而结果奖励的差异被视为该调用的价值：有用的调用为正，误导性的为负，无变化的为零。这种方法复用了现有的答案检查器而无需辅助评判，且由于它是差异值而非绝对探测分数，因此天然地对探测攻击（probe-hacking）具有鲁棒性。第二个是来自最终答案的结果优势，通过结果门控优势路由（OGAR）进行分配：这是一种无参数规则，它以调用结果为条件，仅将信用传递给负责的片段，从而在不添加任何成本项的情况下抑制浪费的工具调用。我们通过两阶段的 SFT+RL 流水线训练 TACO。在感知、推理和通用多模态基准测试上的广泛实验表明，TACO 带来了持续的准确率提升，并学会了仅在工具提供帮助时才调用它们。

## Abstract
Agentic multimodal models perform diverse operations on an image via code and reason over the returned view, an effective paradigm for fine-grained visual question answering. However, code operations can be useful, redundant, or misleading. Outcome-only rewards cannot precisely distinguish these cases, and existing process rewards either fail to attribute final correctness to individual tool calls, or require an external judge model. To address this, we introduce Tool-Augmented Credit Optimization (TACO), a GRPO variant for code-tool agents built on two coupled advantage channels. The first, Differential Answer-Probe Reward (DAPR), is a self-supervised, judge-free tool-contribution advantage that credits each tool call by its own effect on answering correctly. Probe tokens inserted into the model's reasoning elicit its predictions with and without the tool, and the difference in outcome reward is taken as the call's value: positive for a useful call, negative for a misleading one, and zero for one that changes nothing. This reuses the existing answer checker with no auxiliary judge, and, being a difference rather than an absolute probe score, is naturally robust to probe-hacking. The second is the outcome advantage from the final answer, distributed by Outcome-Gated Advantage Routing (OGAR): a parameter-free rule that, conditioned on the call's outcome, delivers this credit only to the responsible segments, suppressing wasted tool calls without any cost term. We train TACO through a two-stage SFT+RL pipeline. Extensive experiments across perception, reasoning, and general multimodal benchmarks show that it yields consistent accuracy gains and learns to invoke its tools only when they help.

### 1. 核心问题与整体含义（研究动机和背景）
在细粒度视觉问答任务中，多模态模型常通过编写代码（如裁剪、缩放图像）来获取更清晰的观察。然而，现有的强化学习方法（如 RLVR）面临两个核心痛点：
*   **信用分配不均：** 仅基于最终结果的奖励（Outcome-only rewards）无法区分工具调用是“有功”（转错为对）、“冗余”（本来就对）还是“误导”（转对为错）。
*   **成本与偏差：** 现有的过程奖励（Process rewards）要么依赖昂贵的外部评判模型（如 GPT-4o），要么无法将正确性精确归因于特定的工具调用步骤。
**TACO 的目标**是提供一种自监督、无需外部评判、且能精确分配信用的训练机制，让智能体学会“只在必要时才使用工具”。

### 2. 方法论：核心思想与关键技术
TACO 基于 **GRPO**（群组相对策略优化）算法，引入了两个耦合的优势通道：

*   **差分答案探测奖励 (DAPR)：**
    *   **核心思想：** 在工具调用前后插入轻量级探针（Probe tokens），分别获取“无工具”时的预测答案 $a_1$ 和“有工具”后的预测答案 $a_2$。
    *   **计算方式：** 工具价值 $\Delta = R(a_2) - R(a_1)$。若 $\Delta > 0$ 表示工具起到了正面作用；$\Delta < 0$ 表示误导；$\Delta = 0$ 表示无影响。
    *   **鲁棒性：** 由于取的是差值，它能抵御“探测攻击”（Probe-hacking），即模型无法通过在推理早期预写答案来刷分，因为差值会抵消掉预存的正确性。

*   **结果门控优势路由 (OGAR)：**
    *   **核心思想：** 根据工具调用的实际效果，动态决定最终答案的奖励（Advantage）应该分发给哪些 Token 片段。
    *   **路由规则：** 
        *   **有用调用：** 奖励分发给全轨迹。
        *   **冗余调用：** 奖励仅分发给预推理片段，不奖励代码片段（抑制浪费）。
        *   **误导调用：** 惩罚分发给代码和后推理片段，保护正确的预推理片段。
        *   **必要但失败：** 豁免对工具分支的惩罚，鼓励在难题上探索工具使用。

*   **训练流程：** 采用两阶段策略：首先进行 SFT（监督微调）冷启动，然后使用 TACO 增强的 GRPO 进行强化学习。

### 6. 主要结论与发现
*   **性能领先：** TACO 在 7B 级别模型中达到了平均 68.1% 的准确率，显著超过了之前的 SOTA（如 PyVision 的 63.7%），甚至在多项指标上超过了 GPT-4o。

*   **防御探测攻击：** 实验证明差分奖励（DAPR）比绝对值奖励更能有效防止模型在强化学习中产生作弊行为。

### 7. 优点
*   **自监督且低成本：** 无需外部昂贵的 Judge 模型（如 GPT-4o），仅利用模型自身的预测差值即可生成高质量过程奖励。
*   **精细化信用分配：** OGAR 机制解决了 RL 中常见的“功过难分”问题，特别是对冗余调用的抑制非常有效。
*   **即插即用：** 作为一个算法变体，它可以轻松迁移到不同的多模态底座模型上。

### 8. 不足与局限
*   **任务类型限制：** 目前主要依赖于可验证的答案（Verifiable answers，如数学题或选择题），对于开放式生成的任务，如何定义 $R(a)$ 仍是挑战。

*   **探针依赖：** 探测结果的质量取决于模型自身的校准能力，如果模型在 SFT 阶段未打好基础，探针给出的反馈可能存在噪声。
