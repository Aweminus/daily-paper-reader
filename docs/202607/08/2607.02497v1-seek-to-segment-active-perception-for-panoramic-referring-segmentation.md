## 摘要
现有的指代分割模型被动地处理从固定视角捕获的静态图像，这限制了它们在具身智能（Embodied AI）中的应用，因为在具身智能中，智能体必须在连续的 360° 环境中进行主动感知。为了弥补这一差距，我们引入了一项新任务：主动全景指代分割（APRS）。在这种设定下，智能体需要调整其视角方向（Δθ, Δφ）来探索 360° 环境，寻找用户指令指定的物体进行分割。为了应对这一具有挑战性的任务，我们提出了 PanoSeeker，一种用于高效 APRS 的记忆增强型智能体。PanoSeeker 不依赖于启发式扫描，而是将视觉语言模型（VLM）与显式空间视觉记忆 EgoSphere 相结合。通过将连续的局部观测逐步整合到统一的 360° 表示中，EgoSphere 使智能体能够规划高效且非冗余的搜索轨迹。一旦找到目标，智能体就会执行主动视角对齐并输出分割掩码。此外，我们策划了一个带有记忆时间线的专家标注搜索轨迹数据集，用于有监督微调，随后进行强化学习后训练，以显式优化 PanoSeeker 的探索效率。在我们新建立的 APRS 基准测试上进行的广泛实验表明，PanoSeeker 实现了卓越的搜索效率和分割准确度，显著优于经过适配的最先进基线模型。

## Abstract
Existing referring segmentation models passively process static images captured from fixed perspectives, limiting their applicability in Embodied AI, where agents must perform active perception in the continuous 360$^\circ$ environments. To bridge this gap, we introduce a novel task: Active Panoramic Referring Segmentation (APRS). In this setting, an agent is required to adjust its viewing direction ($Δθ, Δφ$) to explore the 360$^\circ$ environment, seeking the object specified by a user instruction for segmentation. To tackle this challenging task, we propose PanoSeeker, a memory-augmented agent for efficient APRS. Rather than relying on heuristic scanning, PanoSeeker integrates a Vision-Language Model (VLM) with EgoSphere, an explicit spatial visual memory. By progressively integrating sequential local observations into a unified 360$^\circ$ representation, EgoSphere enables the agent to plan efficient and non-redundant search trajectories. Once the target is found, the agent performs active viewpoint alignment and outputs the segmentation mask. Furthermore, we curate an expert-annotated search trajectory dataset with memory timelines for Supervised Fine-Tuning, followed by Reinforcement Learning post-training to explicitly optimize PanoSeeker's exploration efficiency. Extensive experiments on our newly established APRS benchmark demonstrate that PanoSeeker achieves superior search efficiency and segmentation accuracy, significantly outperforming adapted state-of-the-art baselines.

传统的**指代分割（Referring Segmentation）**任务通常是“被动”的：模型处理的是视角固定的静态图像。然而，在**具身智能（Embodied AI）**场景中，智能体需要像人类一样，在 360° 的连续环境中通过主动旋转视角来寻找并分割目标。
*   **核心挑战**：如何在 360° 环境中进行跨视角的空间推理（如“寻找床对面的柜子”）、如何避免重复探索（冗余搜索）、以及如何处理全景图像的几何畸变。
*   **研究贡献**：提出了**主动全景指代分割（APRS）**新任务，构建了相应的基准测试，并开发了具备空间记忆能力的智能体 **PanoSeeker**。

### 2. 方法论：核心思想与技术细节
PanoSeeker 的核心是一个增强了记忆能力的视觉语言智能体，其工作流程如下：
*   **EgoSphere（显式空间视觉记忆）**：
    *   这是该方法的核心创新。它维护一个等距柱状投影（ERP）画布，将智能体在不同步数观察到的局部透视视图，通过逆向等角投影（Inverse Gnomonic Projection）逐步拼接到 360° 画布上。
    *   **视觉提示增强**：在记忆画布上叠加中心十字准星、经纬度网格线和已走过的轨迹路径，帮助模型感知当前方位和已探索区域。
*   **PanoSeeker 决策核心**：
    *   基于 **Qwen3-VL-8B** 视觉语言模型。输入包括：当前局部观测、EgoSphere 记忆地图、以及用户指令。
    *   模型预测下一步动作（水平/垂直旋转角度）或停止信号（[STOP]）。
*   **训练策略**：
    *   **SFT（有监督微调）**：使用专家标注的搜索轨迹进行初步学习。
    *   **RL（强化学习）**：采用 **GRPO（群体相对策略优化）** 算法。设计了“效率奖励”（鼓励走最短路径）和“终端奖励”（根据最终定位精度和分割 IoU 评分），显式优化搜索效率。
*   **主动对齐与分割**：
    *   在停止搜索后，智能体进行微调对齐，将目标置于视野中心，并调用 **SAM-3** 生成最终的像素级掩码。

### 6. 主要结论与发现
*   **记忆至关重要**：相比于文本日志或简单的图像序列缓存，显式的 360° 空间记忆（EgoSphere）能显著减少重复搜索，SPL 指标提升巨大。
*   **强化学习的价值**：通过 GRPO 优化，智能体不仅能找到目标，还能学会以更少的步数（平均 4.8 步）找到目标。

### 7. 优点
*   **任务创新**：填补了指代分割在 360° 具身场景下的空白。
*   **架构优雅**：EgoSphere 将复杂的 3D 空间感知简化为 2D 全景画布的“填空题”，计算成本低于 3D 点云重建。
*   **训练闭环**：结合了专家经验（SFT）和自主探索优化（RL），使智能体兼具准确性和效率。

### 8. 不足与局限
*   **环境简化**：实验基于静态全景图模拟，虽然模拟了视角旋转，但智能体无法在空间中进行平移（即只能原地转头，不能走动）。
*   **动作离散化**：动作空间被限制在 30° 的倍数，可能在处理极小物体时缺乏精细度。
*   **实时性挑战**：虽然搜索步数减少了，但每一步都需要调用大型 VLM 和更新全景画布，在低功耗嵌入式设备上的实时运行可能存在压力。
