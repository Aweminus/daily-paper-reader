## 摘要
使用因果视觉语言模型的端到端视觉语言导航（VLN）可以将指令和第一人称视角观察直接映射到动作，但标准的行为克隆仅监督下一个动作，并未显式训练策略状态以预测未来的视觉结果。我们首先提出了一个诊断性问题：如果在训练和测试时为策略提供专家轨迹中的未来图像作为特权输入，这些额外的视觉证据是否对选择当前动作有用？（这些专家轨迹未来图像在实际部署的测试阶段是不可用的，因此我们仅将此设置作为特权输入诊断。）答案是肯定的；这一合理性检查表明，未来观察可以提供丰富的、具有行动指导意义的线索。随后我们提出了一个可部署的问题：在推理时不访问未来图像的情况下，我们是否仍能通过仅将压缩的未来视觉潜变量作为训练监督来从未来信息中获益？我们提出了未来状态条件 VLN（FSC-VLN），它增加了一个未来查询（future-query）标记，并通过一个仅在训练时使用的目标分支（训练后移除），将其隐藏状态与 $Δ$ 步之后的冻结视觉嵌入对齐。在 R2R val-unseen 数据集上，FSC-VLN 在两种训练数据方案下均比 StreamVLN 风格的基线模型提升了 SR/OSR/SPL 指标，且在长时程（long-horizon）回合中增益更大；消融实验进一步支持了双查询设计（将未来查询与动作查询分离）。

## Abstract
End-to-end vision-language navigation (VLN) with causal vision-language models can map instructions and egocentric observations directly to actions, but standard behavior cloning supervises only the next action and does not explicitly train the policy state to be predictive of future visual outcomes. We first ask a diagnostic question: if the policy is given an expert-trajectory future image as privileged input at training and testing time, is that additional visual evidence useful for choosing the current action? (These expert-trajectory future images are unavailable at test time in real deployment, so we use this setting only as a privileged-input diagnostic.) The answer is yes; this sanity check shows that future observations can provide rich, actionable cues.   We then ask a deployable question: without accessing future images at inference, can we still benefit from future information by using a compressed future visual latent only as training supervision? We propose Future-State-Conditioned VLN (FSC-VLN), which adds a future-query token and aligns its hidden state to a frozen visual embedding $Δ$ steps ahead via a training-only target branch that is removed after training. On R2R val-unseen, FSC-VLN improves SR/OSR/SPL over a StreamVLN-style baseline under two training-data regimes, with larger gains on long-horizon episodes; ablations further support the dual-query design (separating future and action queries).

*   **研究背景**：当前的视觉语言导航（VLN）智能体主要依赖因果视觉语言模型（VLM）进行端到端训练。
*   **核心痛点**：标准的“行为克隆”（Behavior Cloning, BC）训练模式仅监督智能体的下一个动作，而忽略了对未来视觉状态的预测。这导致模型在长距离导航任务中，由于缺乏对行动后果的预判，容易产生误差累积和轨迹偏离。
*   **研究动机**：作者试图探索：如果让模型在训练时学会“预见”未来的视觉状态，是否能提升其在线导航（尤其是长距离任务）的决策质量，且不增加推理时的计算负担。

### 2. 方法论：FSC-VLN
*   **核心思想**：在因果序列中引入一个专门的“未来查询”标记，通过辅助任务强制模型学习未来视觉特征的表征，并利用因果注意力机制将该表征传递给动作生成模块。
*   **关键技术细节**：
    *   **双查询设计（Dual-Query）**：在输入序列（指令+历史观察）后插入两个可学习的 Token：**未来查询 ($q_F$)** 和 **动作查询 ($q_A$)**。
    *   **未来状态对齐**：在训练阶段，提取专家轨迹中 $\Delta$ 步（实验设定为 32 步）后的图像 $o_{t+\Delta}$。使用冻结的视觉编码器（SigLIP）提取其嵌入向量作为目标（Target）。
    *   **损失函数**：
        1.  **语言模型损失 ($L_{LM}$)**：标准的动作预测交叉熵损失。
        2.  **对齐损失 ($L_{future}$)**：计算 $q_F$ 的隐藏状态与未来图像嵌入之间的 $\ell_1$ 距离。
    *   **因果依赖**：由于 Transformer 的因果掩码机制，$q_A$ 可以感知 $q_F$ 提取的未来预测信息，从而生成更具前瞻性的动作。
    *   **推理流程**：推理时直接丢弃未来图像分支，仅保留 $q_F$ 和 $q_A$。模型仅需一次前向传播即可完成预测与动作生成。

### 6. 主要结论与发现
*   **未来信息至关重要**：诊断实验显示，若能直接看到未来图像，导航成功率（SR）可从 29.96% 提升至 71.77%。
*   **FSC-VLN 显著提升长路径表现**：在长距离任务中，FSC-VLN 相比基线在 SR 上提升了约 **3.85%**（R2R+RxR 制度下），而短距离任务提升较小。
*   **双查询的必要性**：消融实验表明，将“预测未来”和“生成动作”的任务分别交给两个 Token 处理，比共用一个 Token 效果更好，能更有效地转化预测信息为行动。

### 7. 优点
*   **部署友好**：推理时不需要生成图像，也不需要额外的视觉编码器前向传递，仅增加 2 个 Token 的开销，几乎不增加延迟。
*   **架构通用**：该方法作为一种“插件式”的训练策略，可以轻易迁移到其他基于 Transformer 的导航模型中。
*   **理论自洽**：通过因果注意力将“预判”置于“行动”之前，符合人类导航的认知逻辑。

### 8. 不足与局限
*   **整体提升幅度**：虽然在长路径上增益明显，但在全量指标上的绝对提升（约 1%~1.5%）不算巨大。
*   **专家依赖**：训练目标依赖于专家轨迹的未来图像，如果专家数据本身质量不高或存在偏差，模型学习到的预测表征可能会受限。
*   **固定步长限制**：实验中统一使用 $\Delta=32$ 步作为未来目标，但在不同复杂度的场景下，最优的预判跨度可能不同，缺乏动态调整机制。
