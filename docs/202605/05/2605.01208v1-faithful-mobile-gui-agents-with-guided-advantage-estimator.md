## 摘要
基于视觉语言模型的图形用户界面（GUI）智能体已展现出强大的交互能力。然而，它们经常表现出不忠实的行为，依赖记忆的捷径，而非将动作建立在显示的屏幕证据或用户指令之上。为解决这一问题，我们提出了 Faithful-Agent，这是一个忠实度优先的框架，它重新表述了 GUI 交互，以优先考虑证据落地和内部一致性。Faithful-Agent 采用两阶段流水线：(i) 面向忠实度的有监督微调（SFT）阶段，旨在在证据扰动下灌输弃权行为；(ii) 强化微调（RFT）阶段，通过引入引导式优势估计器（GuAE）进一步增强忠实度，GuAE 是一种基于锚点且方差自适应的优势回火机制，构建于 GRPO 之上。GuAE 防止了在稀疏 GUI 奖励下低方差采样组中的优势坍缩，结合思维-动作一致性奖励，Faithful-Agent（第二阶段）相对于基线将陷阱成功率（Trap SR）从 13.88% 提升至 80.21%，同时保持了稳健的通用指令遵循性能。

## Abstract
Vision-language model based graphical user interface (GUI) agents have shown strong interaction capabilities. However, they often behave unfaithfully, relying on memorized shortcuts rather than grounding actions in displayed screen evidence or user instructions. To address this, we propose Faithful-Agent, a faithfulness-first framework that reformulates GUI interaction to prioritize evidence groundedness and internal consistency. Faithful-Agent employs a two-stage pipeline: (i) a faithfulness-oriented SFT stage to instill abstainment behaviors under evidence perturbations; (ii) an RFT stage that further amplifies faithfulness by introducing the guided advantage estimator (GuAE), an anchor-based and variance-adaptive advantage tempering mechanism built upon GRPO. GuAE prevents advantage collapse in low-variance rollout groups under sparse GUI rewards, and with a thought-action consistency reward, Faithful-Agent (Stage II) elevates the Trap SR from 13.88\% to 80.21\% relative to the baseline, while preserving robust general instruction-following performance.

### 论文总结：具有引导式优势估计器的忠实移动端 GUI 智能体 (Faithful-Agent)

#### 1. 核心问题与研究背景
*   **核心问题**：现有的基于视觉语言模型（VLM）的 GUI 智能体在交互中经常表现出“不忠实”（Unfaithful）行为。
*   **研究背景**：
    *   **不扎根交互**：智能体依赖记忆中的操作路径，而非当前屏幕显示的证据（如在按钮被遮挡时仍尝试点击）。
    *   **指令偏离**：当用户指令与当前界面状态冲突时，智能体无法识别矛盾，盲目执行。
    *   **内部不一致**：智能体的推理过程（Thought）与实际执行的动作（Action）脱节。
*   **研究动机**：将 GUI 交互重新定义为“忠实度优先”的问题，要求智能体在证据缺失或冲突时能够“弃权”（Abstain），并保持思维与动作的高度一致。

#### 2. 方法论
Faithful-Agent 采用两阶段训练框架：
*   **阶段 I：面向忠实度的监督微调 (SFT)**
    *   **核心思想**：在训练数据中引入“陷阱”（Trap）案例，教导模型在证据受损时执行弃权动作（如按返回键、主页键或终止任务），建立忠实行为的冷启动先验。
*   **阶段 II：基于引导式优势估计器 (GuAE) 的强化微调 (RFT)**
    *   **核心思想**：在 GRPO 算法基础上改进优势估计，解决 GUI 任务中奖励稀疏导致的优化难题。
    *   **关键技术细节 (GuAE)**：
        *   **锚点正则化 (Anchor Regularization)**：在计算组内优势时，手动加入奖励边界（0 和 1）作为锚点。这确保了即使一组采样结果全部相同（如全部成功或全部失败），优势值也不会坍缩为零，从而保留学习信号。
        *   **方差自适应回火 (VAT)**：根据采样组的方差动态调整优势缩放。在低方差（信号微弱）时锐化信号，在高方差（噪声大）时平滑信号。
    *   **奖励设计**：
        *   **动作匹配奖励 ($R_{AM}$)**：评估动作类型及参数（如坐标距离、文本相似度）的准确性。
        *   **思维-动作一致性奖励 ($R_{Cons}$)**：利用规则检测推理文本与执行动作是否匹配，惩罚“言行不一”。

#### 3. 实验设计
*   **数据集**：基于 **AndroidControl** 和 **AITZ** 构建。
    *   **General 分支**：正常的任务执行轨迹。
    *   **Trap 分支**：包含 UI 遮挡、内容篡改、指令冲突等扰动场景。

*   **评估指标**：动作类型准确率 (Type)、接地准确率 (Grounding)、步骤成功率 (SR)。

#### 6. 主要结论与发现
*   **性能飞跃**：Faithful-Agent 在 Trap 场景下的成功率（SR）从基线的 **13.88% 提升至 80.21%**。
*   **通用性保持**：在大幅提升忠实度的同时，模型在 General 场景下的性能保持稳定（SR 约 65.62%），证明了该方法不会导致模型变得过度保守。
*   **GuAE 的有效性**：实验证明 GuAE 能有效防止 GRPO 在处理近乎二元（0/1）的 GUI 奖励时出现的优势坍缩问题，使训练更稳定。

#### 7. 优点
*   **针对性强**：精准捕捉到了 VLM 智能体在 GUI 领域“幻觉”和“过度自信”的痛点。
*   **算法创新**：提出的 GuAE 机制是对 GRPO 的有力补充，对于奖励空间离散的任务具有普适参考价值。
*   **系统性高**：从数据构造、模型微调到强化学习优化，提供了一套完整的可靠智能体训练方案。

#### 8. 不足与局限
*   **一致性检测依赖规则**：目前的思维-动作一致性奖励主要基于关键词和规则匹配，可能无法完全捕捉复杂的语义逻辑冲突。
*   **数据构造开销**：Trap 数据的构造需要精细的 UI 扰动和指令修改，虽然有自动标注，但仍需一定的人工质量控制。
*   **场景覆盖**：实验主要集中在 Android 移动端，对于 Web 端或跨平台复杂长程任务的泛化能力仍有待进一步验证。
