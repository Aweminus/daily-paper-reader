## 摘要
基于视觉语言模型 (VLM) 的 Web 智能体展示了令人印象深刻的自主 GUI 交互能力，但在欺骗性界面元素面前仍然脆弱。现有方法要么在脱离任务集成的情况下检测欺骗，要么仅记录攻击而不提出防御措施。我们对具备欺骗感知能力的 Web 智能体防御进行了形式化定义，并提出了 DUDE（欺骗性 UI 检测器与评估器），这是一个结合了非对称惩罚的混合奖励学习与经验总结的两阶段框架，旨在将失败模式提炼为可迁移的指导。我们引入了 RUC（真实 UI 点击框），这是一个包含跨越四个领域和欺骗类别的 1,407 个场景的基准测试。实验表明，DUDE 在保持任务性能的同时，将欺骗易感性降低了 53.8%，为稳健的 Web 智能体部署奠定了有效基础。

## Abstract
Vision-language model (VLM) based web agents demonstrate impressive autonomous GUI interaction but remain vulnerable to deceptive interface elements. Existing approaches either detect deception without task integration or document attacks without proposing defenses. We formalize deception-aware web agent defense and propose DUDE (Deceptive UI Detector & Evaluator), a two-stage framework combining hybrid-reward learning with asymmetric penalties and experience summarization to distill failure patterns into transferable guidance. We introduce RUC (Real UI Clickboxes), a benchmark of 1,407 scenarios spanning four domains and deception categories. Experiments show DUDE reduces deception susceptibility by 53.8% while maintaining task performance, establishing an effective foundation for robust web agent deployment.

### 1. 核心问题与整体含义（研究动机和背景）
*   **研究动机**：当前的 Web 智能体（如 UI-TARS、Qwen-VL）虽然在 GUI 任务上表现出色，但在面对现实世界中广泛存在的“暗黑模式”（如虚假下载按钮、诱导性弹窗、伪装广告）时极其脆弱，受骗率高达 70% 以上。
*   **核心问题**：智能体通常将所有 UI 元素视为中性功能，缺乏人类那种通过经验积累形成的“抗欺骗韧性”。
*   **研究目标**：开发一种既能识别欺骗性元素，又不会因过度保守而导致任务失败的防御机制，并将其无缝集成到智能体的决策流程中。

### 2. 方法论：核心思想与关键技术
论文提出了 **DUDE (Deceptive UI Detector & Evaluator)** 框架，包含两个关键阶段：
*   **阶段一：混合奖励学习 (Hybrid-Reward Learning)**：
    *   **核心思想**：通过强化学习（使用 GRPO 算法）校准一个评估器模型，使其具备风险意识。
    *   **非对称惩罚机制**：设计了一种特殊的奖励函数，其中“批准欺骗性点击”的惩罚权重（Severity Weight）远高于“误判正常点击”。
    *   **关键组件**：引入了置信度调整（Confidence Adjustment）以处理决策模糊性，以及注意力标量（Attention Scalar）来衡量不同区域的视觉吸引力。
*   **阶段二：经验总结 (Experience Summarization)**：
    *   **核心思想**：将智能体在训练中遇到的失败案例提炼为可迁移的文本指南（Experience Context）。
    *   **迭代蒸馏**：利用多模态总结器，将失败模式（如“虚假下载按钮通常出现在页面中心”）转化为结构化规则，在推理时作为上下文输入，无需更新参数即可提升性能。
*   **推理流程**：在智能体提出动作后，评估器作为“门控”进行拦截。只有被判定为“良性”的点击才会执行；若判定为“欺骗”或“无效”，则触发“拒绝并重新思考（Reject & Rethink）”循环。

### 3. 实验设计
*   **基准测试 (Benchmark)**：构建了 **RUC (Real UI Clickboxes)** 数据集，包含 1,407 个场景（910 个正常，497 个欺骗性）。涵盖新闻、预订、购物、软件四大领域。
*   **对比模型**：
    *   **智能体基座**：Qwen3-VL-4B、UI-TARS-7B、GLM-4.6V-Flash。
    *   **评估器基座**：Qwen3-VL-2B、UI-TARS-7B。
*   **评估指标**：任务成功率 (SR)、欺骗诱导失败率 (DFR)、平均交互步数 (Steps)。

### 4. 资源与算力
*   **硬件环境**：使用了 **4 台 NVIDIA A100 (80GB VRAM)** GPU。
*   **系统配置**：AMD EPYC 7742 64 核处理器，512GB DDR4 RAM。

*   **训练细节**：模型以 bfloat16 精度加载，启用了梯度检查点（Gradient Checkpointing）以优化显存。

### 5. 实验数量与充分性
*   **实验规模**：在 200 个任务的测试集上进行了全面评估。
*   **消融实验**：
    *   **阶段消融**：对比了仅使用阶段一、仅使用阶段二以及两者结合的效果。
    *   **奖励组件消融**：分别验证了严重性权重、置信度调整和注意力标量的贡献。
    *   **提示词策略对比**：对比了无提示词、人工设计提示词和 DUDE 自动生成的经验提示词。
*   **充分性评价**：实验设计较为客观、公平，不仅涵盖了不同规模的开源模型，还通过零样本迁移实验验证了其在闭源模型（如 GLM）上的泛化能力。

### 6. 主要结论与发现
*   **显著降低风险**：DUDE 将智能体的欺骗易感性（DFR）平均降低了 **53.8%**，在某些配置下甚至能实现零受骗。
*   **意外的增益**：DUDE 不仅防御了欺骗，还显著提升了**任务成功率 (SR)**。这是因为评估器的反馈循环纠正了智能体原本的无效点击（如点在空白处），起到了“纠错引导”的作用。
*   **协同效应**：阶段一提供视觉感知基础，阶段二提供行为约束规则，两者缺一不可。

### 7. 优点
*   **首创性**：首次将欺骗防御形式化为 Web 智能体的核心能力，而非简单的插件式检测。
*   **即插即用**：框架具有高度的模块化，可以适配各种不同的 VLM 基座模型。
*   **双重收益**：通过“拒绝并重新思考”机制，同时解决了安全性和任务准确性问题。
*   **高质量基准**：RUC 数据集填补了真实世界 UI 欺骗行为标注数据的空白。

### 8. 不足与局限
*   **推理延迟**：由于引入了额外的评估器调用，每一步的推理时间略有增加（尽管总任务时间因步数减少而下降）。
*   **静态局限**：实验主要基于静态截图，尚未在完全动态、异步反馈的实时交互环境中进行大规模验证。
*   **语言覆盖**：目前 RUC 基准主要集中在英文界面，跨语言的泛化性有待探索。
*   **后端盲区**：DUDE 依赖视觉感知，无法检测没有视觉表现的后端漏洞（如隐藏脚本注入）。
