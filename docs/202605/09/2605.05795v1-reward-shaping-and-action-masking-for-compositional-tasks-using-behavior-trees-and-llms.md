## 摘要
将复杂任务分解为一系列更简单的子任务可以提高自主智能体的学习效率。强化学习（RL）可用于优化智能体策略以完成子任务，但需要定义明确的子任务奖励，并能从动作掩码中获益。最近的工作利用大语言模型（LLM）来自动化奖励塑造和动作掩码，然而，这些工作都没有充分解决组合任务中对子任务失败的反应性以及针对不同物体的模块化问题。为了克服这些挑战，我们开发了掩码奖励行为树（MRBT），这是一种用作反应式和模块化奖励及动作掩码函数的符号结构。我们设计了一个 MRBT 模板，并推导出逻辑规范，用于构建和验证一系列物体交互子任务的 MRBT。此外，我们开发了一个自动化流水线，利用 LLM 生成对不同任务物体具有鲁棒性的 MRBT，使用 SMT 求解器验证规范的正确性，并通过神经符号 RL 循环在组合任务上训练智能体。实验表明，五个 MRBT 的成功生成和细化，在训练效率和任务成功率上始终优于基线模型以及不带动作掩码的 MRBT。我们进一步强调了 MRBT 的三个优势：可迁移性、模块化和可验证性。

## Abstract
Decomposing complex tasks into a sequence of simpler subtasks can improve learning efficiency for an autonomous agent. Reinforcement learning (RL) can be used to optimize agent policies to complete subtasks, but requires well-defined subtask rewards and benefits from action masking. Recent work uses large language models (LLMs) to automate reward shaping and action masking, however none of them fully address reactivity to subtask failure and modularity to varying objects for compositional tasks. To overcome these challenges, we develop masking reward behavior tree (MRBT), a symbolic structure used as a reactive and modular reward and action mask function. We design an MRBT template and derive logical specifications to construct and verify MRBTs for a sequence of object-interaction subtasks. Further, we develop an automated pipeline that uses an LLM to generate MRBTs robust to varying task objects, an SMT-solver to verify correctness of specifications, and a neurosymbolic RL loop to train agents on compositional tasks. Experiments demonstrate successful generation and refinement of five MRBTs, consistently improving training efficiency and task success rates over baselines and MRBTs without action masking. We further highlight three advantages of MRBTs: transferability, modularity, and verifiability.

### 1. 核心问题与整体含义（研究动机）
强化学习（RL）在处理复杂的组合任务（如机器人装配、无人机递送）时，面临奖励稀疏和搜索空间巨大的挑战。虽然利用大语言模型（LLM）自动化奖励塑造（Reward Shaping）已有研究，但现有方法存在两个核心痛点：
*   **缺乏反应性（Reactivity）：** 当某个子任务失败时（如抓取的物体掉落），现有系统往往无法有效地回溯并重新尝试。
*   **缺乏模块化（Modularity）：** 难以适应任务中物体属性（如颜色、位置）的变化。
*   **缺乏验证：** LLM 生成的代码或逻辑可能存在错误，缺乏形式化的验证机制。

本研究提出了一种**掩码奖励行为树（MRBT）**框架，旨在通过符号化的行为树结构，结合 LLM 的推理能力和 SMT 求解器的验证能力，为组合任务提供具备反应性、模块化且可验证的奖励函数与动作掩码。

### 2. 方法论
核心思想是将任务分解为行为树（BT），利用 BT 的层级结构和回溯机制来管理子任务的执行逻辑。

*   **MRBT 结构：** 行为树的叶子节点被定义为“掩码行为奖励机（MBRM）”。每个节点不仅输出标量奖励，还输出动作掩码（Action Mask），限制智能体在特定阶段只能执行相关的动作（如导航阶段屏蔽抓取动作）。
*   **MRBT 模板：** 针对“物体交互”类任务设计了通用模板。每个子任务包含：
    *   `ψ` (Completion)：子任务完成的逻辑判断。
    *   `ϕ` (Proximity)：靠近目标的逻辑判断。
    *   `η` (Masks)：导航和交互阶段的动作掩码。
*   **自动化流水线：**
    1.  **生成：** LLM（如 ChatGPT-5）根据任务描述和环境谓词生成子任务逻辑公式和掩码。
    2.  **验证：** 使用 SMT 求解器（Z3）根据预定义的逻辑规范（如完成性、非平凡性、非回归性）对生成的公式进行验证。
    3.  **细化：** 如果验证失败，求解器返回反例，LLM 根据反例重新生成逻辑。
    4.  **训练：** 将验证后的 MRBT 集成到神经符号 RL 循环中，指导智能体策略优化。

### 6. 主要结论与发现
*   **性能提升：** MRBT 在所有任务中均显著提高了训练效率和最终成功率。在最复杂的 LockedRoom 任务中，MRBT 达到了 >80% 的成功率，而基线方法均低于 70%。
*   **动作掩码的作用：** 动作掩码显著缩小了搜索空间，尤其在复杂任务中，它是提升学习效率的关键。
*   **反应性的价值：** 在随机动力学环境下，具备回溯机制的 MRBT 表现远优于顺序执行的 Procedure 方法，证明了 BT 处理意外失败的能力。
*   **验证的必要性：** SMT 求解器成功识别并修正了 LLM 生成的逻辑错误（如未考虑物体遮挡导致的逻辑失效）。

### 7. 优点
*   **神经符号结合：** 将符号逻辑（BT）的严谨性与深度强化学习的泛化能力结合，解决了纯神经方法难以处理的长程组合任务。
*   **闭环验证：** 引入 SMT 求解器对 LLM 输出进行形式化验证，提高了系统的可靠性，减少了“幻觉”影响。
*   **高度模块化：** 相比奖励机（Reward Machines），行为树在扩展子任务时具有更低的复杂度（O(1) 存储增长 vs O(k)）。

### 8. 不足与局限
*   **模板依赖：** 目前的方法依赖于预定义的 MRBT 模板，主要适用于顺序物体交互任务，对于非线性或更复杂的逻辑结构可能需要重新设计模板。
*   **符号环境模型：** 验证过程需要环境的符号化表示（谓词逻辑），在完全未知或极度复杂的视觉环境中，构建这种符号模型可能存在困难。
*   **动作掩码偏差：** 实验中发现，如果动作掩码设计过于严苛，可能会限制智能体学习到更优的非直觉策略（虽然在本文实验中影响较小）。
