## 摘要
基于大语言模型（LLM）的智能体在组合泛化方面表现出系统性失效，限制了其在交互式环境中的鲁棒性。本研究引入了 AGEL-Comp，这是一种神经符号 AI 智能体架构，旨在通过锚定（grounding）智能体动作来应对这一挑战。AGEL-Comp 集成了三项核心创新：(1) 动态因果程序图（CPG）作为世界模型，将过程性和因果性知识表示为有向超图；(2) 归纳逻辑程序设计（ILP）引擎，从经验反馈中合成新的霍恩子句（Horn clauses），通过交互锚定符号知识；(3) 混合推理核心，由 LLM 提出一组候选子目标，并由神经定理证明器（NTP）验证其逻辑一致性。这些组件共同实现了一个“演绎-溯因”（deduction--abduction）学习循环：使智能体能够演绎出计划，并溯因式地扩展其符号世界模型，同时神经自适应阶段使推理引擎与新知识保持一致。我们在 Retro Quest 模拟环境中提出了一套评估协议，用于探测组合泛化场景以评估我们的 AGEL 智能体。研究结果清楚地表明，AGEL 模型的性能优于纯基于 LLM 的模型。我们的框架为开发能够对其世界建立显式、可解释且具有组合结构化理解的智能体提供了一条原则性路径。

## Abstract
Large Language Model (LLM)-based agents exhibit systemic failures in compositional generalization, limiting their robustness in interactive environments. This work introduces AGEL-Comp, a neuro-symbolic AI agent architecture designed to address this challenge by grounding actions of the agent. AGEL-Comp integrates three core innovations: (1) a dynamic Causal Program Graph (CPG) as a world model, representing procedural and causal knowledge as a directed hypergraph; (2) an Inductive Logic Programming (ILP) engine that synthesizes new Horn clauses from experiential feedback, grounding symbolic knowledge through interaction; and (3) a hybrid reasoning core where an LLM proposes a set of candidate sub-goals that are verified for logical consistency by a Neural Theorem Prover (NTP). Together, these components operationalize a deduction--abduction learning cycle: enabling the agent to deduce plans and abductively expand its symbolic world model, while a neural adaptation phase keeps its reasoning engine aligned with new knowledge. We propose an evaluation protocol within the \texttt{Retro Quest} simulation environment to probe for compositional generalization scenarios to evaluate our AGEL agent. Our findings clearly indicate the better performance of our AGEL model over pure LLM-based models. Our framework presents a principled path toward agents that build an explicit, interpretable, and compositionally structured understanding of their world.

*   **核心问题**：大语言模型（LLM）在交互式智能体中存在“组合泛化危机”。尽管 LLM 擅长统计模式匹配，但在面对已知组件的新颖组合时，往往因缺乏对世界结构化、因果性的理解而失败。
*   **研究动机**：当前的 LLM 智能体缺乏“锚定”（Grounding），即抽象符号与现实世界后果之间的联系。作者认为，真正的泛化不能仅靠神经规模（Scaling）实现，而需要一种能够学习、表示并对显式结构化知识进行推理的架构。

### 2. 方法论：AGEL-Comp 框架
AGEL-Comp（Action-Grounded Experiential Learning for Compositionality）集成了神经模型与符号系统的优势，核心包含三个组件：
*   **因果程序图（CPG）作为世界模型**：将知识表示为有向超图，节点为谓词，超边为霍恩子句（Horn clauses）。这种结构使程序依赖关系显式化，便于分层规划。
*   **归纳逻辑编程（ILP）引擎**：
    *   **最小对比搜索（MCS）**：当预测与实际反馈不符时，通过对比成功与失败的经验，识别导致失败的单一变量（因果归因）。
    *   **元解释学习（MIL）**：将识别出的因果关系泛化为可重用的符号规则，并更新至 CPG。
*   **混合推理核心（LLM + NTP）**：
    *   **LLM 作为规划器**：生成候选子目标。
    *   **神经定理证明器（NTP）作为验证器**：在连续向量空间中执行可微分的反向链接推理，验证 LLM 提议的逻辑一致性。
*   **学习循环**：通过“演绎（规划）- 动作 - 反馈 - 溯因（学习新规则）”的循环，智能体不断修正其世界模型，并通过神经自适应阶段微调 NTP 的符号嵌入。

### 6. 主要结论与发现
*   **性能卓越**：AGEL-Comp 完整系统在所有 LLM 骨干下均实现了 **100% 的任务成功率**，而基准模型在困难任务中表现崩溃（成功率降至 0%）。

*   **协同效应**：消融实验证明，仅有验证器（w/o ILP）或仅有学习器（w/o NTP）都无法应对复杂的组合任务。

### 7. 优点
*   **可解释性**：通过 CPG 和符号规则，智能体的知识库是显式且可读的。
*   **架构创新**：成功将 LLM 的生成灵活性与符号逻辑的严谨性结合，解决了纯神经模型难以处理的逻辑一致性问题。
*   **高效学习**：MCS 算法提供了一种简洁的解决信用分配（Credit Assignment）问题的方法。

### 8. 不足与局限
*   **感知噪声**：实验假设感知模块能提供准确的结构化谓词，但在现实世界（非模拟环境）中，从原始像素提取准确符号仍具挑战。
*   **可扩展性风险**：随着 CPG 规模的无限增长，NTP 的推理深度和 ILP 的搜索空间可能会面临性能瓶颈。
*   **Sim-to-Real 差距**：目前仅在 2D 模拟环境中验证，尚未在具有高度不确定性和连续动作空间的真实物理机器人上测试。
