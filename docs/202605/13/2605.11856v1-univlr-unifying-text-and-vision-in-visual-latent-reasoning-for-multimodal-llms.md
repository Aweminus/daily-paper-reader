## 摘要
多模态大语言模型（MLLMs）被越来越多地期望能够结合图像进行思考，然而现有的视觉潜空间推理方法仍然依赖于与视觉潜标记（visual latent tokens）交织的显式文本思维链（CoT）。这种交织设计限制了效率，并使推理过程在独立的文本和视觉通道中保持碎片化。我们提出了 UniVLR，这是一个统一的视觉潜空间推理框架，它将文本推理和辅助视觉证据视为一个共享的视觉工作空间。UniVLR 不再将文本 CoT 保留为独立的推理路径，而是将推理轨迹与辅助图像共同渲染，并学习将这种统一表示压缩为紧凑的视觉潜标记。在推理阶段，模型仅通过视觉潜变量进行推理并直接解码最终答案，从而避免了外部工具调用和冗长的文本推理。在真实世界感知和视觉推理任务上的实验表明，UniVLR 在使用显著更少的生成推理标记的情况下，性能优于先前的视觉潜空间推理方法，这为 MLLMs 中的视觉思考提供了一种更统一且高效的范式。

## Abstract
Multimodal large language models are increasingly expected to perform thinking with images, yet existing visual latent reasoning methods still rely on explicit textual chain-of-thought interleaved with visual latent tokens. This interleaved design limits efficiency and keeps reasoning fragmented across separate text and vision channels. We propose UniVLR, a unified visual latent reasoning framework that treats textual reasoning and auxiliary visual evidence as a shared visual workspace. Instead of preserving text CoT as an independent inference-time path, UniVLR renders reasoning traces together with auxiliary images and learns to compress this unified representation into compact visual latent tokens. At inference time, the model reasons only through visual latents and directly decodes the final answer, avoiding both external tool calls and verbose text reasoning. Experiments on real-world perception and visual reasoning tasks show that UniVLR outperforms prior visual latent reasoning methods while using substantially fewer generated reasoning tokens, suggesting a more unified and efficient paradigm for visual thinking in MLLMs.

在处理复杂的视觉感知任务（如几何解题、图表分析、高分辨率理解）时，多模态大语言模型（MLLM）需要“结合图像思考”。现有的视觉潜空间推理方法通常采用**交替设计**：即显式的文本思维链（Text CoT）与隐式的视觉潜标记（Visual Latent Tokens）交替生成。
*   **研究动机**：作者指出这种交替设计存在两个瓶颈：
    1.  **效率低下**：尽管引入了潜空间推理，但仍需生成冗长的文本 CoT，推理成本并未显著降低。
    2.  **推理碎片化**：文本和视觉通道异构，模型往往过度依赖文本而忽略了早期的辅助图像证据，导致视觉信息整合不足。
*   **核心目标**：提出 UniVLR，将文本推理轨迹和辅助视觉证据统一渲染到一个共享的“视觉画布”中，使模型能够完全在视觉潜空间内进行高效、连贯的思考。

#### 2. 方法论：核心思想与技术细节
UniVLR 的核心思想是**“阅读即视觉感知”**，将文本推理过程转化为视觉信号。
*   **统一视觉画布渲染（Unified Visual Canvas Rendering）**：
    *   将文本推理步骤 $R$ 和辅助图像 $U$（如裁剪图、标注图）通过渲染函数 $\Phi$ 合成为一张统一的画布图像。
    *   采用自适应渲染策略（调整字体、行宽、布局），确保信息紧凑且可读。
    *   利用视觉编码器提取特征，并通过**长宽比感知的 2D 池化**将其压缩为固定长度 $K$ 的视觉潜标记序列。
*   **两阶段对齐训练**：
    *   **阶段 I：视觉潜空间接地（Visual Latent Grounding）**：使用辅助图像作为对齐目标，训练模型生成具有语义意义的连续视觉潜标记。
    *   **阶段 II：文本-视觉统一对齐（Text-Vision Unified Alignment）**：将渲染后的“文本+图像”统一画布作为目标，训练模型通过潜标记同时承载推理逻辑和视觉证据。
*   **算法流程与损失函数**：
    *   模型在生成 `<|univlr_start|>` 后进入潜推理模式，预测连续向量 $\hat{z}_k$。

#### 7. 优点（亮点）

*   **鲁棒性**：通过两阶段课程学习，解决了连续潜空间训练不稳定的问题，且在不同规模的潜标记预算下表现稳健。

#### 8. 不足与局限
*   **可解释性挑战**：虽然证明了潜标记有效，但它们不像文本 CoT 那样直观易读，给调试和安全审计带来困难。

*   **固定预算限制**：目前使用固定的潜标记数量（如 12 或 24），而不同难度的任务可能需要动态调整推理步数。
*   **工具互补性**：对于需要精确测量或极高分辨率搜索的任务，UniVLR 仍无法完全取代专门的外部视觉工具。
