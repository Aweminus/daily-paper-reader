## 摘要
在语言推理中，更长的思维链（Chain of Thought）始终能带来更好的性能，这自然地暗示了视觉潜空间推理可能同样受益于更长的潜序列。然而，我们发现了一个反直觉的现象：现有视觉潜空间推理方法的性能随着潜序列变长而系统性地下降。我们揭示了其根本原因：信息增益崩溃（Information Gain Collapse）——自回归生成使得每一步都高度依赖于先前的输出，导致后续的 token 几乎无法引入新信息。我们进一步发现，作为监督目标的重度池化（≥ 128×）图像嵌入所提供的信号并不比无意义的占位符更多。基于这些见解，我们提出了 SCOLAR（Self-COnsistent LAtent Reasoning），它引入了一个轻量级的 detransformer，利用大语言模型（LLM）的全序列隐藏状态一次性生成辅助视觉 token，且每个 token 都独立地锚定在原始视觉空间中。结合三阶段有监督微调（SFT）和 ALPO 强化学习，SCOLAR 将可接受的潜空间思维链（latent CoT）长度扩展了 30 倍以上，在真实世界推理基准测试中达到了开源模型的最先进水平（比基准模型提升了 14.12%），并展示了强大的分布外泛化能力。

## Abstract
In language reasoning, longer chains of thought consistently yield better performance, which naturally suggests that visual latent reasoning may likewise benefit from longer latent sequences. However, we discover a counterintuitive phenomenon: the performance of existing latent visual reasoning methods systematically degrades as the latent sequence grows longer. We reveal the root cause: Information Gain Collapse -- autoregressive generation makes each step highly dependent on prior outputs, so subsequent tokens can barely introduce new information. We further identify that heavily pooled ($\geq 128\times$) image embeddings used as supervision targets provide no more signal than meaningless placeholders. Motivated by these insights, we propose SCOLAR (Self-COnsistent LAtent Reasoning), which introduces a lightweight detransformer that leverages the LLM's full-sequence hidden states to generate auxiliary visual tokens in a single shot, with each token independently anchored to the original visual space. Combined with three-stage SFT and ALPO reinforcement learning, SCOLAR extends acceptable latent CoT length by over $30\times$, achieves state-of-the-art among open-source models on real-world reasoning benchmarks (+14.12% over backbone), and demonstrates strong out-of-distribution generalization.

### 1. 论文的核心问题与整体含义
*   **研究动机**：在语言模型中，思维链（CoT）越长通常性能越强。研究者试图将此逻辑迁移至视觉领域，通过在潜空间引入视觉推理步骤来增强 VLM。
*   **核心发现**：作者发现了一个反直觉现象——现有视觉潜空间推理方法（如 LVR、Monet）的性能随推理序列增长而**系统性下降**。
*   **根本原因**：
    1.  **信息增益坍缩（Information Gain Collapse）**：自回归生成模式使得后续 token 高度依赖前序输出，导致视觉信息在传递中不断衰减，无法引入新信息。
    2.  **监督信号微弱**：现有方法常使用重度池化（≥128×）的图像嵌入作为目标，这些信号在语义上几乎等同于无意义的噪声。

### 2. 方法论
作者提出了 **SCOLAR（自一致潜空间推理）** 框架，核心思想是打破自回归依赖，实现“单次生成、独立锚定”。
*   **Detransformer 架构**：引入一个轻量级的两层 Transformer 分支。它不采用自回归方式，而是直接利用 LLM 的全序列隐藏状态，**一次性（Single-shot）**生成与输入分辨率一致的辅助视觉 token。
*   **独立锚定机制**：每个生成的辅助 token 都直接与原始视觉空间关联，确保即使序列很长，每个 token 依然携带真实的视觉语义。
*   **三阶段 SFT 训练流程**：
    1.  **预训练**：训练 Detransformer 进行视觉特征重建。
    2.  **触发词学习**：通过加权交叉熵损失学习何时输出 `<auxiliary>` 触发 token。
    3.  **联合推理与退火**：采用“教师强制退火（Teacher-forcing annealing）”策略，使模型从依赖真实辅助图像平滑过渡到依赖自身生成的潜变量。
*   **ALPO 强化学习**：提出“辅助潜变量策略优化（Auxiliary Latents Policy Optimization）”，解决了连续潜变量无法直接应用离散策略梯度（如 GRPO）的问题，通过缓存辅助嵌入来优化文本策略。
