## 摘要
具有可验证奖励的强化学习（RLVR）传统上依赖于稀疏的、基于结果的信号。最近的研究表明，提供细粒度的模型内在信号（奖励正确答案置信度的增长）可以通过提供步骤级引导来有效改进语言推理训练，且无需昂贵的外部模型。虽然这种方法对单模态文本有效，但我们发现将这种全局奖励简单地应用于视觉-语言（V-L）推理是一种次优策略，因为该任务是稀疏视觉感知和密集文本推理的异构混合。这种全局归一化会导致混合引起的信号退化，其中视觉步骤的训练信号会被占主导地位的文本步骤在统计上扭曲。我们提出了感知分解置信度奖励（PDCR），这是一个通过使奖励结构与任务的异构性质保持一致来解决该问题的框架。PDCR 首先执行无监督技能分解，引入模型内部的视觉依赖分数（Visual Dependence Score）来量化视觉依赖性，并应用聚类算法来分离感知和推理步骤。在此基础上，PDCR 通过在每个技能簇内对置信度增益进行归一化来计算分解后的优势（advantage）。这种簇内归一化为感知和推理提供了稳定且尺度正确的信号。我们证明了 PDCR 在关键的视觉-语言推理基准测试中优于朴素的全局奖励方案和稀疏奖励基准。

## Abstract
Reinforcement Learning with Verifiable Rewards (RLVR) traditionally relies on a sparse, outcome-based signal. Recent work shows that providing a fine-grained, model-intrinsic signal (rewarding the confidence growth in the ground-truth answer) effectively improves language reasoning training by providing step-level guidance without costly external models. While effective for unimodal text, we find that naively applying this global reward to vision-language (V-L) reasoning is a suboptimal strategy, as the task is a heterogeneous mix of sparse visual perception and dense textual reasoning. This global normalization creates mixture-induced signal degradation, where the training signal for visual steps is statistically distorted by the predominant textual steps. We propose Perception-Decomposed Confidence Reward (PDCR), a framework that solves this by aligning the reward structure with the task's heterogeneous nature. PDCR first performs an unsupervised skill decomposition, introducing a model-internal Visual Dependence Score to quantify visual reliance and applying a clustering algorithm to separate perception and reasoning steps. Based on this, PDCR computes a decomposed advantage by normalizing confidence gains within each skill cluster. This intra-cluster normalization provides a stable, correctly-scaled signal for both perception and reasoning. We demonstrate that PDCR outperforms the naive, global-reward formulation and sparse-reward baselines on key V-L reasoning benchmarks.

### PDCR：面向视觉-语言推理的感知分解置信度奖励论文总结

#### 1. 论文的核心问题与整体含义（研究动机和背景）
论文关注的是**视觉-语言（V-L）推理任务中的强化学习（RL）优化问题**。
*   **背景**：目前的视觉语言模型（VLM）常采用具有可验证奖励的强化学习（RLVR，如 DeepSeek-R1 风格的训练）。传统的稀疏奖励（仅看最终答案对错）存在信度分配困难。
*   **动机**：虽然最近的研究（如 PACR）提出利用模型对正确答案的“置信度增长”作为中间步骤的密集奖励，但在 V-L 任务中，推理过程是**异构的**：包含稀疏但关键的“视觉感知”步骤和密集的“文本推理”步骤。
*   **核心问题**：如果对所有步骤进行全局奖励归一化，占主导地位的文本步骤会掩盖视觉步骤的信号，导致“混合引起的信号退化”（Mixture-induced signal degradation），使得模型无法有效学习如何从图像中提取关键证据。

#### 2. 论文提出的方法论：PDCR 框架
PDCR 的核心思想是将感知和推理步骤分开评价，确保每种技能都能获得正确缩放的奖励信号。
*   **无监督技能分解**：
    *   **视觉依赖得分（VDS）**：计算模型在有原图输入和无信息输入（如纯白图像）下生成该步骤的对数概率之差。差值越大，说明该步骤越依赖视觉输入。
    *   **动态阈值聚类**：利用图像处理中经典的 **Otsu 算法（大津法）**，在无人工标注的情况下，自动找到最优阈值，将推理步骤划分为“视觉感知”和“文本推理”两个簇。
*   **感知分解优势计算（Decomposed Advantage）**：
    *   不再进行全局归一化，而是在各自的簇（感知簇或推理簇）内分别进行 Min-Max 归一化。
    *   这种**簇内归一化**确保了感知步骤的奖励是与其同类步骤相比的，从而提供了更稳定、比例更合理的训练信号。
*   **最终奖励组合**：将分解后的过程奖励与最终结果的稀疏奖励（Outcome Reward）加权结合，用于策略更新（如 GRPO 算法）。

#### 3. 实验设计
*   **模型底座**：Qwen2.5-VL-3B/7B-Instruct，以及最新的 Qwen3-VL-8B。
*   **训练数据集**：Vision-SR1（约 4.7 万条数据），涵盖数学、常识和通用视觉理解。
*   **评测基准（7个）**：
    *   通用视觉理解：MMMU, MMMU-Pro, RealWorldQA, VisNumBench。
    *   多模态数学推理：MathVerse, MATH-Vision。
    *   幻觉诊断：HallusionBench。
*   **对比方法**：GRPO（纯稀疏奖励）、DAPO（稳定版 GRPO）、PACR（全局密集奖励）。

#### 4. 资源与算力
*   **硬件**：使用了单节点 **8 张 NVIDIA A100 80GB GPU**。
*   **训练配置**：在 Vision-SR1 数据集上训练 1 个 epoch。
*   **开销说明**：相比 PACR，PDCR 增加了一次额外的推理前向传播（用于计算白图下的概率），训练成本约为 GRPO 的 1.5 倍以上，但作者强调这换来了推理时更高的效率（模型学会了更简洁的推理路径）。

#### 5. 实验数量与充分性
*   **实验规模**：论文在 3 个不同规模和版本的模型底座上进行了验证，覆盖了 7 个主流基准测试。
*   **消融实验**：
    *   验证了**随机分解**与 PDCR 自动分解的效果对比，证明了 VDS 得分的有效性。
    *   对比了不同的图像扰动策略（白图、高斯模糊、噪声、旋转），证明了“破坏信息”类扰动对识别感知步骤最有效。
    *   进行了人工标注一致性分析（与 GPT-5 标注对比），验证了无监督分类的准确性。
*   **充分性评价**：实验设计非常全面，不仅关注准确率，还分析了训练动力学、推理长度和计算成本，结果具有较强的说服力和客观性。

#### 6. 论文的主要结论与发现
*   **性能提升**：PDCR 在所有基准测试中均优于 GRPO 和 PACR。在 7B 模型上，平均性能比 PACR 提升了约 0.7%，比 GRPO 提升了 1.4%。
*   **解决信号退化**：通过分解奖励，视觉感知步骤的优势分布得到了更好的对齐，有效缓解了因文本步骤过多导致的信号稀释。
*   **推理效率**：PDCR 训练的模型倾向于生成更短、更简洁的推理链（CoT），从而显著提升了推理速度。
*   **减少幻觉**：定性分析显示，PDCR 能显著减少因视觉提取错误导致的逻辑误判（即减少了“一本正经胡说八道”的情况）。

#### 7. 优点：亮点总结
*   **针对性强**：敏锐捕捉到了多模态推理中“感知”与“逻辑”统计分布不均的痛点。
*   **无监督且自包含**：不需要额外的外部奖励模型（PRM）或人工标注，完全依赖模型自身逻辑，易于扩展。
*   **算法优雅**：巧妙地将图像分割中的 Otsu 算法引入到推理步骤分类中，解决了硬编码阈值不灵活的问题。

#### 8. 不足与局限
*   **计算开销**：训练期间需要多次前向传播来获取置信度和视觉依赖得分，增加了训练时长和显存压力。
*   **二元假设**：目前仅将步骤简单划分为“感知”或“推理”，但实际中可能存在既包含感知又包含复杂逻辑的“混合步骤”，二元分类可能过于简化。
*   **白图依赖**：虽然实验证明白图有效，但对于某些特定领域的图像，简单的白图可能不足以完全作为“无信息”的基准。
