## 摘要
视觉-语言-动作（VLA）模型有望实现通用机器人操控，但通常作为短时界策略进行训练和部署，这类策略假设最新的观测结果足以进行动作推理。这一假设在非马尔可夫长时界任务中失效，因为在这些任务中，与任务相关的证据可能会被遮挡，或者仅出现在轨迹的早期阶段，且杂乱的环境和干扰项会使细粒度的视觉定位变得脆弱。我们提出了 CodeGraphVLP，这是一个分层框架，通过将持久的语义图状态与可执行的基于代码的规划器以及进度引导的视觉-语言提示相结合，实现了可靠的长时界操控。语义图在部分可观测条件下维护与任务相关的实体及其关系。合成的规划器在语义图上执行，以进行高效的进度检查，并输出子任务指令及相关的子任务对象。我们利用这些输出构建抑制杂波的观测结果，使 VLA 执行器能够专注于关键证据。在真实世界的非马尔可夫任务中，CodeGraphVLP 的任务完成率优于强大的 VLA 基准模型和支持历史信息的变体，同时与 VLM 在环规划相比，显著降低了规划延迟。我们还进行了广泛的消融研究，以确认各组件的贡献。

## Abstract
Vision-Language-Action (VLA) models promise generalist robot manipulation, but are typically trained and deployed as short-horizon policies that assume the latest observation is sufficient for action reasoning. This assumption breaks in non-Markovian long-horizon tasks, where task-relevant evidence can be occluded or appear only earlier in the trajectory, and where clutter and distractors make fine-grained visual grounding brittle. We present CodeGraphVLP, a hierarchical framework that enables reliable long-horizon manipulation by combining a persistent semantic-graph state with an executable code-based planner and progress-guided visual-language prompting. The semantic-graph maintains task-relevant entities and relations under partial observability. The synthesized planner executes over this semantic-graph to perform efficient progress checks and outputs a subtask instruction together with subtask-relevant objects. We use these outputs to construct clutter-suppressed observations that focus the VLA executor on critical evidence. On real-world non-Markovian tasks, CodeGraphVLP improves task completion over strong VLA baselines and history-enabled variants while substantially lowering planning latency compared to VLM-in-the-loop planning. We also conduct extensive ablation studies to confirm the contributions of each component.

### 1. 核心问题与整体含义（研究动机和背景）
现有的视觉-语言-动作（VLA）模型（如 OpenVLA, $\pi_0$ 等）大多基于**马尔可夫假设**，即认为当前的视觉观测足以决定下一步动作。然而，在真实的长程（Long-horizon）机器人任务中，这一假设往往失效：
*   **非马尔可夫性**：任务进度依赖于历史信息（例如：物体被遮挡后需记住其位置，或需记住之前是否已经移动过某个物体）。
*   **环境干扰**：杂乱场景中的无关物体（Distractors）会干扰 VLA 的视觉定位，导致动作错误。
*   **效率瓶颈**：现有的分层模型（VLM 规划 + VLA 执行）通常需要频繁调用大语言模型（LLM/VLM）进行在线规划，导致高延迟，难以满足闭环控制的需求。

### 2. 方法论：核心思想与技术细节
CodeGraphVLP 提出了一种分层框架，核心思想是**“用结构化图表征记忆，用代码逻辑进行规划，用视觉掩码过滤干扰”**。

*   **持久化语义图状态 (Persistent Semantic-Graph State)**：
    *   **初始化**：利用实例分割（YOLOE）和 VLM 识别任务相关物体，通过跨视角关联和几何规则诱导物体间的关系（如 `in`, `on`, `near`），构建初始图 $G_0$。
    *   **在线更新**：使用视频物体分割（Cutie）在每一帧跟踪物体，并定期通过分割模型修正漂移，确保在部分观测下依然能维护环境状态。
*   **代码即规划器 (Code-as-Planner)**：
    *   **单次合成**：在任务开始前，利用 LLM（如 GPT-5）根据任务指令和初始图状态合成一段 Python 代码。
    *   **轻量化执行**：该代码作为高层规划器，通过查询语义图来检查任务进度（利用代码中的 `task_memory` 记录已完成步骤），并输出当前子任务指令及相关物体列表。这避免了每一步都调用昂贵的 VLM。
*   **进度引导的视觉-语言提示 (Progress-Guided VLP)**：
    *   **子任务语言提示**：将长程指令分解为简短的子任务指令。
    *   **无杂波视觉提示**：根据规划器输出的相关物体，对原始图像进行掩码处理（Black-out），仅保留任务关键物体，从而引导 VLA 执行器专注于核心证据。

### 3. 实验设计
*   **实验场景**：使用 UR10e 机械臂在真实世界桌面环境下进行测试。
*   **任务设置**：设计了三个具有非马尔可夫依赖的任务：
    1.  **Pick-and-Place Twice**：将方块移到另一个盘子再移回原位（需区分初始和最终状态）。
    2.  **Place-and-Stack**：将方块放入杯中（方块被遮挡）并叠放另一个杯子（需记忆方块位置）。
    3.  **Swap Cups**：交换两个杯子的位置（需利用缓冲区并记住交换顺序）。
*   **对比基准 (Benchmarks)**：
    *   **基础 VLA**：$\pi_0$, $\pi_0$ FAST, $\pi_{0.5}$, Gr00T N1.5。
    *   **历史增强型**：支持多帧历史输入的 Gr00T N1.5。
    *   **消融变体**：不带视觉掩码的本方法、基于 VLM 在线规划的变体。

### 6. 主要结论与发现
*   **性能领先**：CodeGraphVLP 在所有非马尔可夫任务上的成功率显著高于所有基线模型（平均成功率 81.7%，而最强基线仅为 56.7%）。
*   **低延迟**：相比于每步调用 VLM 的规划方式，CodeGraphVLP 的规划延迟降低了约 **90%**（从 ~3秒 降至 ~0.3秒）。
*   **抗干扰能力**：视觉掩码（Clutter-free prompting）被证明是提升 VLA 在复杂场景下鲁棒性的关键，移除该组件会导致成功率从 85% 降至 40%。

### 7. 优点
*   **架构优雅**：巧妙地结合了符号化逻辑（代码/图）与神经网络（VLA），兼具推理的严谨性和控制的灵活性。
*   **效率高**：通过一次性代码合成替代重复的 VLM 调用，极大地提升了闭环控制的频率。
*   **可解释性**：代码规划器和语义图提供了清晰的中间推理过程，便于调试和理解机器人的决策逻辑。

### 8. 不足与局限
*   **依赖基础模型**：语义图的构建和代码的合成高度依赖于底层 VLM/LLM 的能力，如果初始识别错误或代码逻辑有误，系统将无法正常工作。
*   **环境动态性限制**：虽然有在线更新机制，但在极度动态或物体频繁进出视野的场景下，语义图的维护可能面临挑战。
*   **提示词敏感性**：代码生成阶段可能需要精细的 Prompt Engineering 才能确保生成的 Python 逻辑完全符合任务约束。
