## 摘要
目前的具身智能体通常局限于被动的指令遵循或反应式的需求满足，缺乏对于长期、自主行为以及解决动机冲突至关重要的高阶稳定价值框架。我们提出了 ValuePlanner，这是一种将高层价值调度与底层动作执行解耦的分层认知架构。ValuePlanner 利用基于大语言模型（LLM）的认知模块，通过对抽象价值权衡进行推理来生成符号化子目标，随后由经典的 PDDL 规划器将其转化为可执行的动作计划。该过程通过闭环反馈机制进行优化。评估此类自主性需要超越任务成功率的方法，因此我们提出了一套以价值为中心的评估体系，用于衡量累积价值增益、偏好对齐和行为多样性。在 TongSim 家庭环境中的实验表明，ValuePlanner 能够协调相互竞争的价值，生成连贯、长程且自主的行为，而这些行为在指令遵循和需求驱动的基准模型中是不存在的。我们的工作为桥接自主智能体的内在价值与落地行为提供了一种结构化方法。

## Abstract
Current embodied agents are often limited to passive instruction-following or reactive need-satisfaction, lacking a stable, high-order value framework essential for long-term, self-directed behavior and resolving motivational conflicts. We introduce \textit{ValuePlanner}, a hierarchical cognitive architecture that decouples high-level value scheduling from low-level action execution. \textit{ValuePlanner} employs an LLM-based cognitive module to generate symbolic subgoals by reasoning through abstract value trade-offs, which are then translated into executable action plans by a classical PDDL planner. This process is refined via a closed-loop feedback mechanism. Evaluating such autonomy requires methods beyond task-success rates, and we therefore propose a value-centric evaluation suite measuring cumulative value gain, preference alignment, and behavioral diversity. Experiments in the TongSim household environment demonstrate that \textit{ValuePlanner} arbitrates competing values to generate coherent, long-horizon, self-directed behavior absent from instruction-following and needs-driven baselines. Our work offers a structured approach to bridging intrinsic values and grounded behavior for autonomous agents.

具身智能体（Embodied Agents）目前面临的主要瓶颈是**被动性**。现有的智能体大多属于“指令遵循型”（仅在接收外部命令时行动）或“需求驱动型”（仅在生理指标如能量过低时做出反应）。它们缺乏一个稳定的、高阶的价值框架来引导长期的自主行为，也无法在多个相互冲突的动机（例如：是先打扫房间还是先休息）之间进行权衡。

#### 2. 方法论：ValuePlanner 架构
论文提出了一种名为 **ValuePlanner** 的分层神经符号（Neuro-Symbolic）认知架构，其核心思想是将高层的“价值决策”与底层的“动作执行”解耦：

*   **内在价值系统（Intrinsic Value System）：** 基于 Schwartz 的基本价值理论，将其适配为 7 个维度：生理安全、环境安全、享乐主义、刺激、成就、管家精神（Stewardship）和丰富性（Enrichment）。智能体的“人格”由这些维度的权重向量 $w$ 定义。
*   **高层价值推理器（LLM-based Cognitive Governor）：**
    *   **生成器（Generator）：** 利用 LLM 根据当前环境状态和价值偏好生成符号化的子目标序列。
    *   **评论家（Critic）：** 通过迭代的“生成-评论”循环，对计划的价值增益和逻辑质量进行审计和优化。
*   **底层动作落地与适配（Symbolic Action Grounder）：**
    *   使用 **PDDL 规划器**（如 Fast Downward）将抽象子目标转化为具体的原子动作序列，确保物理和逻辑的一致性。
    *   **闭环调整机制（Adjustment）：** 在执行过程中，根据环境反馈动态修正计划。如果执行失败，LLM 会诊断原因；如果成功，则寻找合并后续目标的协同机会。
*   **价值增益公式：** 目标是最大化累积价值增益 $\Delta V = \sum w^T \Delta V_t$，其中 $\Delta V_t$ 是客观的环境状态变化，$w$ 是主观的人格权重。

#### 6. 主要结论与发现
*   **性能优越：** ValuePlanner 在价值增益和动作多样性上显著优于所有基准模型，证明了分层架构和“生成-评论”循环的有效性。

*   **闭环优势：** 调整机制不仅能修复错误，还能通过识别环境中的协同机会（如顺手带走垃圾）来优化执行效率。

#### 7. 优点与亮点
*   **理论扎实：** 将成熟的心理学价值理论（Schwartz 理论）转化为可计算的具身智能动机模型。
*   **神经符号结合：** 巧妙结合了 LLM 的语义推理能力和 PDDL 的形式化验证能力，有效解决了 LLM 在长程规划中的幻觉和物理约束违背问题。

*   **计算成本：** 依赖高频调用高性能 LLM（如 GPT-4o/5），且多轮“生成-评论”循环可能带来较高的推理延迟和成本。
